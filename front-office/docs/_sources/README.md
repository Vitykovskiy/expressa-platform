# Источники

Служебный каталог фиксирует, где проверять факты о front-office. Это не
описание текущего поведения и не замена [карте документации](../INDEX.md).

## Структура каталога

```text
_sources/
└── README.md         # приоритет первичных источников
```

## Проверка фактов

Текущее поведение подтверждают исходный код и тесты рядом с ним, например
[точка сборки](../../src/app/App.vue) и
[браузерный сценарий меню](../../tests/e2e/menu.e2e.spec.ts). Внешний
HTTP-контракт задаёт [OpenAPI](../../contracts/openapi.json), а команды и
требования к окружению — [package.json](../../package.json) и конфигурация.
При расхождении код определяет текущее поведение, а OpenAPI — внешний контракт.

Каждый фактический блок документации заканчивается ссылкой на первичный источник;
метаданные `sources` его не заменяют. Секреты и значения локального окружения
в ноты не вносятся. [Источник: environment](../../src/shared/config/environment.ts).
