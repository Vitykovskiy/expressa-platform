# Журнал

Служебный каталог для кратких временных заметок по текущей работе. Он не
описывает действующее поведение приложения; устойчивые решения фиксируются в
[ADR](../50-adr/ADR-001-runtime-and-storybook-boundaries.md).

## Структура каталога

```text
_journal/
└── README.md         # назначение и границы служебных заметок
```

Заметка нужна, когда помогает завершить текущую работу. Фактическое поведение
клиента описывают [карта документации](../INDEX.md), код и тесты.
