# Expressa front-office

Автономный клиент Expressa на Vue 3, Vuetify, Pinia и Vite.

Используйте Node.js `24.15.0` из `.nvmrc`.

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run lint
npm run typecheck
npm test -- --run
npm run build
npm run contract:check
```
