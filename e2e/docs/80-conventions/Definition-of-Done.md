# Definition of Done для standalone E2E

Документ задаёт критерии приёмки E2E-кода. Структуру кода определяет [Code Style](Code-style.md), а UI-only границу — [ADR-001](../20-architecture/ADR/ADR-001-standalone-e2e-architecture.md).

## Сценарий и границы

- Spec проверяет пользовательский сценарий через Playwright UI и имеет русское имя.
- Подготовка данных, действия и проверки не обходят UI через API, БД, Web Storage, прямое изменение сети или другой технический канал.
- Сценарий независим от порядка запуска: использует собственные данные либо подтверждённые предусловия и очищает созданные данные через UI, если интерфейс поддерживает удаление.
- Изменение не затрагивает тестируемые приложения, их локальные E2E-наборы и инфраструктуру запуска без отдельного решения.

## Объекты и ожидания

- Локаторы, UI-действия и ожидания находятся в Page/Component Objects; spec вызывает их публичные предметные методы.
- Новый или изменяемый объект содержит одноимённые `*.constants.ts`, `*.types.ts`, `*.page.ts` либо `*.component.ts`; типы и константы не объявляются внутри класса.
- Локаторы используют устойчивый UI-контракт: роли, доступное имя, подпись, `data-testid` или стабильный идентификатор.
- После действия есть web-first ожидание видимого пользователю результата. Фиксированные задержки и ожидания внутренних технических событий не используются.
- Имена шагов и UI-ассертов написаны по-русски и описывают ожидаемый эффект.

## Код, данные и документация

- Изменение минимально: без временных обходов, отладочного кода, сфокусированных и отключённых тестов.
- `fixtures/test.ts` собирает зависимости, `support/data` содержит предметные данные, `support/config` читает и проверяет окружение. Секреты и учётные данные не фиксируются в spec или документации.
- Изменение сценария, объекта, fixture, данных, конфигурации или правил сопровождается актуализацией соответствующей ноты в `e2e/docs`.

## Проверки

Перед завершением нетривиальной задачи выполняются применимые команды из `package.json`:

```bash
npm run lint
npm run format:check
npm run typecheck:e2e
npm run e2e:boundaries
```

Полные E2E-сценарии запускаются только с предоставленными `E2E_FRONT_OFFICE_URL` и `E2E_BACK_OFFICE_URL`.
