# Карта standalone E2E-сценариев

Этот каталог предназначен для карточек будущих сквозных браузерных сценариев. Предметные сценарии, POM-объекты, локаторы, учётные данные и тестовые данные пока не перенесены и не создаются стартовым каркасом.

Будущий Q-E2E связывает действия администратора, клиента и сотрудника через отдельно запущенные интерфейсы. Его ожидаемый пользовательский результат и место в приёмке описаны в [проверке готовности и выпуска](../../../docs/95-testing/Release-verification.md).

## Правило добавления

- Каждая карточка размещается в [scenarios](scenarios/) после согласования предметной области.
- Карточка фиксирует пользовательский путь, предусловия, ожидаемый результат и соответствующий `spec`.
- Сценарий использует только UI Playwright и оба обязательных URL окружения; подготовка через API, БД, storage или изменение сети не допускается.
