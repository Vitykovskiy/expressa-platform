# Критические сквозные пути

## JOURNEY-01 — Публикация товара

### Назначение

Проверить, что администратор создаёт публикуемую конфигурацию напитка, а
клиент видит её в публичном меню.

### Предусловия

В тестовом окружении доступны администратор и клиент с одноразовыми кодами.
Для сценария выбраны уникальные названия категории, напитка, группы и добавки.

### Сценарий

1. Администратор открывает административное приложение.
2. Администратор указывает номер телефона.
3. Администратор запрашивает одноразовый код.
4. Администратор указывает одноразовый код.
5. Администратор подтверждает номер телефона.
6. Администратор открывает управление меню.
7. Администратор начинает создание категории.
8. Администратор указывает название категории.
9. Администратор указывает описание категории.
10. Администратор сохраняет категорию.
11. Администратор начинает создание напитка.
12. Администратор выбирает категорию напитка.
13. Администратор выбирает тип напитка.
14. Администратор указывает название напитка.
15. Администратор указывает описание напитка.
16. Администратор оставляет единственный размер M.
17. Администратор устанавливает цену размера M.
18. Администратор сохраняет напиток.
19. Администратор открывает управление группами добавок.
20. Администратор начинает создание группы добавок.
21. Администратор указывает название группы добавок.
22. Администратор делает выбор обязательным.
23. Администратор выбирает одиночный тип группы.
24. Администратор добавляет вариант добавки.
25. Администратор указывает название добавки.
26. Администратор устанавливает нулевую цену добавки.
27. Администратор выбирает добавку по умолчанию.
28. Администратор сохраняет группу добавок.
29. Администратор открывает назначения категории.
30. Администратор выбирает группу добавок категории.
31. Администратор сохраняет назначения категории.
32. Администратор выходит из административного приложения.
33. Клиент открывает публичное меню.
34. Клиент открывает категорию.
35. Клиент открывает напиток.
36. Клиент выбирает размер M.

### Ожидаемый результат

- Созданная категория открывает опубликованный напиток.
- В публичном меню показан созданный напиток.
- После открытия напитка обязательная добавка выбрана по умолчанию.
- Карточка напитка позволяет выбрать размер M.
- Цена напитка соответствует опубликованной администратором цене.
