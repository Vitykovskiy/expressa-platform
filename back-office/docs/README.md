# Документация back-office

Здесь собраны проверяемые сведения о рабочем PWA сотрудников: его сценариях,
границе API, устройстве UI и проверках. Полная навигация находится в
[локальной карте](INDEX.md).

## Структура каталога

```text
docs/
├── 10-architecture/  # устройство UI и владельцы состояния
├── 30-domains/       # вход, роли, каталог, маршруты и API-ошибки
├── 80-conventions/   # правило размещения runtime-кода
├── 95-testing/       # команды и браузерные проверки
├── ADR/              # принятые архитектурные решения
├── _journal/         # служебный операционный контекст
├── _sources/         # проверяемые внешние материалы и снимки
├── COVERAGE.md       # связь сценариев с кодом, API и тестами
├── INDEX.md          # локальная карта документации
└── README.md         # вход в этот каталог
```

## Как пользоваться

- [README приложения](../README.md)
  — запуск, основные команды и границы контура.
- [INDEX.md](INDEX.md)
  — маршруты к деталям без поиска по тексту.
- [COVERAGE.md](COVERAGE.md)
  — первичные источники для сверки сценариев с runtime, API и тестами.
