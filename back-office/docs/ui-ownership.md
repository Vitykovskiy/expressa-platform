# Владение UI back-office

[App.vue](../src/app/App.vue) владеет тонкой оболочкой: названием приложения, статической навигацией, местом для активной страницы и общим уведомлением об ошибке. Он не загружает данные и не выполняет предметные действия.

[src/pages](../src/pages) собирает отдельные маршруты. [src/shared/ui](../src/shared/ui) содержит локальные повторно используемые примитивы; `ErrorNotice` получает только `ScreenError` и сообщает закрытие событием `close`. Состояние уведомления принадлежит [app.store.ts](../src/app/app.store.ts), поэтому страница или будущая пользовательская область не управляет оболочкой напрямую.

При добавлении UI раздела сохраняется направление зависимостей `app -> pages -> widgets -> features -> entities -> shared`. Визуальный компонент не обращается к API и не хранит техническую ошибку HTTP.
