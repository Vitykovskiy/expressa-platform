# Документация Expressa

Здесь собраны межконтурные правила, архитектурные решения, контракты и
эксплуатационные материалы Expressa. Детали реализации находятся в документации
каждого приложения; актуальное устройство системы ведёт карта ниже.

## Структура каталога

```text
docs/
├── 00-meta/          # правила ведения и проверки документации
├── 10-overview/      # обзор системы и планирование работ
├── 20-architecture/  # межконтурная архитектура и ADR
├── 30-domain/        # предметные понятия и правила
├── 40-features/      # сквозные пользовательские возможности
├── 40-quality/       # требования к качеству
├── 50-interfaces/    # контракты взаимодействия приложений
├── 70-deployment/    # окружения, поставка и эксплуатация
├── 80-conventions/   # инженерные соглашения
├── 90-agents/        # материалы для работы агентов
├── 95-testing/       # межконтурная стратегия проверки
├── _journal/         # исторические записи о документации
├── _sources/         # зафиксированные исходные материалы
├── COVERAGE.md       # реестр покрытия документацией
└── INDEX.md          # карта актуального знания о системе
```

## Как пользоваться

- [Карта документации](INDEX.md) ведёт к актуальным материалам по задаче.
- Детали реализации: [backend](../backend/docs/INDEX.md),
  [front-office](../front-office/docs/INDEX.md),
  [back-office](../back-office/docs/INDEX.md) и [e2e](../e2e/docs/INDEX.md).
- [Реестр покрытия](COVERAGE.md) помогает оценить документированность области.
