# Управление меню

### 6.5. Управление меню

1. Administrator открывает раздел меню.
2. Administrator создаёт и упорядочивает категории.
3. Administrator создаёт напитки с одним или несколькими размерами из `S`, `M`, `L` и остальные товары без размеров.
4. Administrator задаёт цену каждого размера напитка либо единую цену товара без размера.
5. Administrator создаёт группы добавок и варианты добавок.
6. Administrator связывает группы добавок с категориями.
7. Administrator публикует элементы через признак активности.
8. Публичное меню отражает актуальную структуру.

### 8.7. Управление меню

- **FR-ADM-001.** Administrator создаёт, редактирует, архивирует и упорядочивает категории.
- **FR-ADM-002.** Administrator создаёт, редактирует, архивирует и упорядочивает товары.
- **FR-ADM-004.** Administrator задаёт доступные для напитка размеры из `S`, `M`, `L` и их цены, а для остальных товаров — единую цену.
- **FR-ADM-005.** Administrator задаёт обязательность группы добавок, одиночный или множественный выбор, допустимое количество и набор вариантов по умолчанию.
- **FR-ADM-006.** Administrator управляет добавками и изменением цены.
- **FR-ADM-007.** Administrator связывает группы добавок с категориями.
- **FR-ADM-008.** Backend не позволяет двум активным категориям занимать одну позицию в меню или двум товарам занимать одну позицию внутри категории. Группа добавок связывается только с существующей категорией.
- **FR-ADM-009.** Архивирование категории, товара или добавки не изменяет ранее оформленные заказы.
