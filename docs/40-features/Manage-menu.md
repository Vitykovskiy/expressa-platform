# Управление меню

Administrator получает административный каталог и управляет категориями,
товарами, ценами, группами и вариантами модификаторов и связями категорий.
Сохраняются серверный порядок, архивирование, предметная валидация и аудит.
Актуальная модель цен определена [ADR-008](../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md),
точные команды — [API back-office](../50-interfaces/Back-office-API.md).

При редактировании сотрудник сохраняет введённые данные до подтверждённого
результата. Ошибка валидации относится к соответствующему полю;
неоднозначный результат записи требует проверки серверного состояния.
Состояния и права определяет [UI-контракт](../50-interfaces/Back-office-UI.md).

Сценарий не назначает маршрут, диалог, дерево компонентов или store.
Их выбирают заново по [ADR-011](../20-architecture/ADR/ADR-011-back-office-clean-slate.md).

## Группы опций и связи категории

Администратор сначала сохраняет пустую группу опций. В диалоге доступны
название, переключатель вида группы при создании и флаг «Единственное значение»
с пояснением «Можно выбрать только одно значение группы». Затем отдельным
действием добавляет опции: группу, название и целую цену, включая0 ₽.
Редактирование опции открывает отдельный диалог этой опции. Строк опций,
редактора значений по умолчанию и минимального/максимального выбора в диалоге
группы нет. Группа с флагом разрешает выбрать одну опцию; без флага — несколько.

Первой считается неархивная опция с наименьшим сохранённым `sortOrder`
(при равенстве — ID). Она является значением по умолчанию, в том числе если
платная. Новые опции добавляются в конец; имя и цена порядок не меняют.
Архивирование первой делает следующую первой. Изменение доступности не меняет
порядок или default; недоступная первая опция не заменяется другой автоматически.
Серверные правила обязательных ранее созданных групп сохраняются при их
изменении через полные legacy-команды. Source-сохранение группы задаёт простой
необязательный выбор `minSelect=0`, позволяющий сначала сохранить пустую группу.

Категория назначает несколько групп через мультиселект. Порядок выбранных ID
сохраняется. Source-контракт `optionGroupIds: uuid[]`: при создании массив
обязателен; при редактировании отсутствие сохраняет связи, пустой массив
удаляет их. Все ID проверяются до записи; имя, связи и аудит атомарны.
Удаление сохранённых связей подтверждается с именами групп; отмена сохраняет
черновик. Собственных групп у товара нет: все его опции определяет категория.
Прежняя продуктовая привязка исключена из публичного меню, проверки заказа и
seed, без переноса её объединения на другие товары категории.

Обычное молоко по0 ₽ и альтернативное по40 ₽ — взаимоисключающие опции одной
группы. Сахар с вариантами «С сахаром»/«Без сахара» также использует одиночный
выбор; сироп может оставаться необязательным. Штучная еда сохраняется как товар
с одной ценой в категории «Поесть», без размеров и наследуемых кофейных опций.
