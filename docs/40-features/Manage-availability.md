# Управление доступностью

Barista и Administrator находят товар, ценовую опцию или добавку и меняют
оперативную доступность; отдельно управляют приёмом новых заказов.
Категория помогает найти нужную позицию, поиск сужает доступный набор.
Права, требуемые сведения и состояния задаёт [UI-контракт](../50-interfaces/Back-office-UI.md).

После действия предварительное значение не выдаётся за подтверждённый успех.
При определённой ошибке восстанавливается подтверждённое состояние;
при неизвестном исходе клиент проверяет серверное состояние без слепого
повтора изменения. Автор и время последнего изменения отражают доступные
серверные данные без вымышленных значений.

[Доступность](../30-domain/Availability.md), [аудит](../30-domain/Audit.md)
и [API](../50-interfaces/Back-office-API.md) владеют инвариантами и обменом.
Вид элементов управления, группировка на экране и маршрут выбираются заново
по [ADR-011](../20-architecture/ADR/ADR-011-back-office-clean-slate.md).

Внутри категории товар показан одной родительской строкой, размеры — вложенными
строками с подписью и ценой без повторения названия товара. Размеры видны сразу.
У штучного товара с одной фиксированной ценой есть только строка товара;
группы добавок остаются отдельно.

Общий переключатель показывает сохранённую доступность товара, а не сумму
состояний размеров. Когда товар выключен, переключатели размеров выключены
и недоступны для действия; подпись «Весь напиток выключен» объясняет причину.
При включении товара восстанавливаются собственные настройки размеров.
Частично включённый набор показывает, например, «1 из 2 размеров»;
при включённом товаре и всех выключенных размерах — «Нет доступных размеров».
В этом случае общий переключатель остаётся включённым, а нужный размер можно
включить отдельно. Касание переключателя имеет область не меньше 44 × 44 px.

После подтверждённой записи клиент перечитывает всю доступность и только затем
разрешает следующую команду. Если запись подтверждена, но чтение не удалось,
прежняя иерархия остаётся видимой и неактуальной; доступно только обновление.
Неизвестный исход также разрешается чтением без повторной записи. Уход со
страницы не отменяет уже отправленную команду; смена сеанса отзывает её результат.
Время изменения приёма заказов сохраняет прежнюю часовую зону, дату и автора,
но не содержит видимого суффикса UTC.
