# Карта документации Expressa

Корневые ноты описывают систему, межконтурные контракты и поставку. Детали
реализации находятся в [backend](../backend/docs/INDEX.md),
[front-office](../front-office/docs/INDEX.md), [back-office](../back-office/docs/INDEX.md).

## Начать чтение

[Правила чтения](00-meta/How-to-use-this-vault.md) объясняют роль каждого источника. Краткая карта для агента — [llms.txt](../llms.txt). Эта страница маршрутизирует вопросы; статус реализации проверяется в конечной ноте и её первичных источниках.

| Продуктовое или предметное поведение                    | [Обзор](10-overview/INDEX.md), затем [предметная область](30-domain/INDEX.md) или [сценарии](40-features/INDEX.md)                                      | Нормативный контракт в своей области.                             |
| Пользовательский интерфейс и сценарий                   | [Сценарии](40-features/INDEX.md), затем карта затронутого [front-office](../front-office/docs/INDEX.md) или [back-office](../back-office/docs/INDEX.md) | Сценарий и контракт интерфейса; работающий код — факт реализации. |
| HTTP API или иной интерфейс                             | [Интерфейсы](50-interfaces/INDEX.md), затем [HTTP API backend](../backend/docs/50-api/INDEX.md) и затронутый контур                                     | Контракт и факт реализации.                                       |

| Окружение, поставка или проверка работающего приложения | [Поставка](70-deployment/INDEX.md) и при необходимости карта затронутого контура                                                                        | Операционная инструкция и факт реализации.                        |
| Требования к разработке, DoD и проверка                 | [Индекс требований разработки](80-conventions/INDEX.md), [проверка](95-testing/INDEX.md), [агенты](90-agents/INDEX.md)                                  | Применимые правила, DoD и состояние процесса.                     |
