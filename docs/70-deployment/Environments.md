# Среды

- **Q-OPS-001.** Каждый сервис валидирует переменные окружения при запуске и публикует актуальный `.env.example`.
- **Q-OPS-002.** Каждый репозиторий собирает минимальный production Docker image с непривилегированным пользователем и health-check.
- **Q-OPS-003.** Ноты в `docs/70-deployment/` описывают `local`, `development`, `staging` и `production`, их конфигурацию и порядок запуска.
- **Q-OPS-004.** Каждый репозиторий автономно разворачивает совместимую версию в общую среду `development`.
- **Q-OPS-005.** Проверенные совместимые версии продвигаются в `staging` для демонстрации и приёмки пользователем.
- **Q-OPS-006.** Развёртывание в `production` включается после завершения разработки и приёмки MVP.

- `local` — разработка конкретного репозитория;
- `development` — общий стенд команды с последними совместимыми версиями; front-office и back-office используют размещённый здесь backend без его локального запуска;
- `staging` — стабильный стенд для демонстрации текущего состояния и приёмки пользователем; сюда продвигаются только проверенные версии из `development`;
- `production` — рабочая среда кофейни; до завершения разработки и приёмки MVP не разворачивается.

Правила версий и продвижения: [[Release-and-version-compatibility]]. Проверки поставки: [[CI-CD]].
