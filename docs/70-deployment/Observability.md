# Наблюдаемость

Backend публикует `/health/live` для процесса и `/health/ready` для готовности зависимостей. Docker health-check backend использует live, а `deploy/deploy.sh` после миграций проверяет ready. Front-office и back-office имеют `/health` для проверки контейнеров.

Middleware добавляет или принимает корректный `x-request-id`, возвращает его клиенту и пишет структурированные события запроса. Исключения сохраняют request ID; клиенты показывают его в экранной ошибке. Внутренний счётчик фиксирует HTTP-ответы, API-ошибки и ошибки readiness.

Метрики не экспортируются в систему мониторинга, панели и оповещения не настроены. В частности, нет доказанного оповещения о readiness, 5xx или резервной копии. Поэтому эксплуатационная наблюдаемость не считается принятой.
