# Источники инструкций для агента

Автоматически применимые ограничения принадлежат [корневому AGENTS.md](../../AGENTS.md) и локальным правилам: [backend](../../backend/AGENTS.md), [front-office](../../front-office/AGENTS.md), [back-office](../../back-office/AGENTS.md). Эта нота служит навигацией и не копирует их условия.

Для задачи используйте [индекс требований разработки](../80-conventions/INDEX.md); роли, применимость и состояние процесса описаны в [агентной системе](../80-conventions/Agent-system.md). Краткий вход — [llms.txt](../../llms.txt), роли предметных источников — [правила чтения](../00-meta/How-to-use-this-vault.md).

Global skills находятся вне репозитория и читаются по актуальным путям клиента. Проект не содержит их копий; пример из skill не становится командой Expressa без проверки по manifest, коду или поддерживаемой инструкции.
