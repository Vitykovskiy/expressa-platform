# BL-0013 Back-office обязан поставляться Docker-образом

## Результат

Back-office поставляется минимальным production Docker-образом с непривилегированным пользователем и health-check.

## Требуемое поведение

- Собирать образ в pipeline back-office.
- Запускать приложение без привилегий и с проверкой здоровья.

## Критерии приёмки

- Docker build проходит в CI back-office.
- Образ содержит health-check и не запускает процесс от root.
