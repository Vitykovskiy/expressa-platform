# BL-0015 Состав backend CI задан канонически

## Результат

CI backend выполняет полный путь npm ci, качества, OpenAPI, сборки, Docker и развёртывания.

## Требуемое поведение

- Запускать lint, typecheck, модульные и интеграционные тесты PostgreSQL, OpenAPI check, production и Docker build.
- Для main развёртывать development после green checks; тег развёртывает staging из manifest digest.

## Критерии приёмки

- Ошибка любого обязательного шага останавливает pipeline.
- Тег `staging-v*` запускает staging после green checks; старые runs не доказывают новый delivery.
