# BL-0011 Backend обязан поставляться Docker-образом

## Результат

Backend поставляется минимальным production Docker-образом с непривилегированным пользователем и health-check.

## Требуемое поведение

- Собирать образ в pipeline backend.
- Запускать процесс без привилегий и с проверкой здоровья.

## Критерии приёмки

- Docker build проходит в CI backend.
- Образ содержит health-check и не запускает процесс от root.
