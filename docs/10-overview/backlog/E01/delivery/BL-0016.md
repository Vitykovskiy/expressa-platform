# BL-0016 Состав front-office CI включает Storybook-gates

## Результат

CI front-office выполняет npm ci, качество, Storybook, сборку, Docker, development E2E и tagged staging.

## Требуемое поведение

- Запускать lint, typecheck, тесты, interaction, accessibility, visual regression, Storybook и application build front-office.
- Публиковать front-office Storybook preview и его visual regression для каждого pull request.

## Критерии приёмки

- Main выполняет front-office E2E с backend в development.
- Тег версии выполняет front-office E2E и browser smoke в staging.
