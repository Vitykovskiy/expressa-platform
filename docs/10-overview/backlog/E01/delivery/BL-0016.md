# BL-0016 Состав front-office CI задан канонически

## Результат

CI front-office выполняет npm ci, качество, сборку, Docker, same-origin browser-check
в development и tagged staging.

## Требуемое поведение

- Запускать lint, typecheck, тесты, OpenAPI check, application и Docker build front-office.
- Для main выполнять same-origin browser-check в development, для тега — в staging.
- Storybook, interaction, accessibility, visual regression и preview принадлежат
  [[../../E02/front-office/BL-0020|BL-0020]], [[../../E02/front-office/BL-0037|BL-0037]]
  и [[../../E02/delivery/BL-0038|BL-0038]].
- Полный browser E2E трёх приложений принадлежит
  [[../../E12/quality/BL-0152|BL-0152]].

## Критерии приёмки

- Main выполняет front-office same-origin browser-check в development.
- Тег версии выполняет front-office same-origin browser-check в staging.
