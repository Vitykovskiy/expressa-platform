# BL-0017 Состав back-office CI включает Storybook-gates

## Результат

CI back-office выполняет npm ci, качество, Storybook, сборку, Docker, development E2E и tagged staging.

## Требуемое поведение

- Запускать lint, typecheck, тесты, interaction, accessibility, visual regression, Storybook и application build back-office.
- Публиковать back-office Storybook preview и его visual regression для каждого pull request.

## Критерии приёмки

- Main выполняет back-office E2E с backend в development.
- Тег версии выполняет back-office E2E и browser smoke в staging.
