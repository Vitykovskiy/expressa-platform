# BL-0017 Состав back-office CI задан канонически

## Результат

CI back-office выполняет npm ci, качество, сборку, Docker, same-origin browser-check
в development и tagged staging.

## Требуемое поведение

- Запускать lint, typecheck, тесты, OpenAPI check, application и Docker build back-office.
- Для main выполнять same-origin browser-check в development, для тега — в staging.
- Storybook, interaction, accessibility, visual regression и preview принадлежат
  [[../../E03/back-office/BL-0040|BL-0040]], [[../../E03/back-office/BL-0057|BL-0057]]
  и [[../../E03/delivery/BL-0058|BL-0058]].
- Полный browser E2E трёх приложений принадлежит
  [[../../E12/quality/BL-0152|BL-0152]].

## Критерии приёмки

- Main выполняет back-office same-origin browser-check в development.
- Тег версии выполняет back-office same-origin browser-check в staging.
