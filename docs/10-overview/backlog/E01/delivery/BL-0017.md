# BL-0017 Состав back-office CI задан канонически

## Результат

CI back-office выполняет npm ci, качество, сборку и Docker; live same-origin проверка выполняется в development и staging.

## Требуемое поведение

- Запускать lint, typecheck, тесты, OpenAPI check, application и Docker build back-office.
- После поставки проверять same-origin в development и staging.
- Пользовательские потоки принимаются вручную в работающем development-окружении.

## Критерии приёмки

- CI и Docker build green в runs `30750587887` и `30750840290`; после них отдельная read-only live same-origin проверка пройдена в development и staging.
