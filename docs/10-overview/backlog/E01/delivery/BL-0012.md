# BL-0012 Front-office обязан поставляться Docker-образом

## Результат

Front-office поставляется минимальным production Docker-образом с непривилегированным пользователем и health-check.

## Требуемое поведение

- Собирать образ в pipeline front-office.
- Запускать приложение без привилегий и с проверкой здоровья.

## Критерии приёмки

- Docker build проходит в CI front-office.
- Образ содержит health-check и не запускает процесс от root.
