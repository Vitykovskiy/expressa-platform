# BL-0014 Каноничны local/development/staging/production, не test

## Результат

Конфигурация поставки различает local, development, staging и production.

## Требуемое поведение

- Определить назначение и порядок запуска каждой среды.
- Не вводить отдельную среду test как контур поставки.
- Зафиксировать: `local` для одного репозитория, `development` для совместимой команды, `staging` для демонстрации и приёмки, `production` для кофейни после MVP.

## Критерии приёмки

- Development использует совместимый backend без его локального запуска клиентами.
- Staging принимает только проверенные версии из development.
- Production не разворачивается до завершения разработки и приёмки MVP.
