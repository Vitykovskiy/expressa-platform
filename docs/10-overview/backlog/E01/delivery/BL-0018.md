# BL-0018 Каноничен development для совместимой поставки

## Результат

Каждый репозиторий автономно развёртывает совместимую версию в development.

## Требуемое поведение

- Автоматически обновлять development из основной ветки.
- Сохранять traceability от head SHA GitHub run к трём immutable image digest.
- Клиенты используют размещённый совместимый backend без его локального запуска.

## Критерии приёмки

- Клиенты используют размещённый совместимый backend.
- GitHub run связывает head SHA с тремя immutable image digest development.
- Обновление development не требует Git-тега версии.
