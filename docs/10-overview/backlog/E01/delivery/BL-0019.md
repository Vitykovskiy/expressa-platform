# BL-0019 Выпуск строится через теги и immutable staging

## Результат

Staging использует тег и три immutable Docker digest.

## Требуемое поведение

- Тег `staging-v*` запускает staging после green CI трёх приложений.
- Staging читает три digest из `deploy/staging.env`, не пересобирает и не использует latest.
- Manual production promotion после MVP принадлежит
  [BL-0161](../../E12/delivery/BL-0161.md). E01 не создаёт production workflow
  или среду.

## Критерии приёмки

- `staging-v0.1.2` и run `30750840290` подтвердили развёртывание трёх digest.
