# BL-0010 Локальные маршруты, store, API-клиент и ошибки обязательны

## Результат

Back-office содержит локальные маршруты-заглушки, состояние, API-клиент и обработку ошибок.

## Требуемое поведение

- Разделять очередь, доступность и меню в локальной навигации-заглушке.
- Проверять API-клиент back-office по снимку OpenAPI-контракта.
- Следовать [канонической архитектуре клиентов](../../../../20-architecture/Client-architecture.md): back-office владеет своим контуром, включая локальный `shared`.
- Вход и runtime-права принадлежат [BL-0071](../../E04/back-office/BL-0071.md),
  [BL-0072](../../E04/back-office/BL-0072.md) и [BL-0073](../../E04/back-office/BL-0073.md).
- Очередь принадлежит [BL-0117](../../E08/back-office/BL-0117.md), доступность —
  [BL-0142](../../E11/back-office/BL-0142.md), управление меню —
  [BL-0090](../../E06/back-office/BL-0090.md).

## Критерии приёмки

Подтверждено back-office CI: локальные маршруты, OpenAPI snapshot и error UI.

- Ошибка API не подтверждает действие в интерфейсе.
- Изменение API, не совпадающее со снимком OpenAPI, останавливает проверку клиента.
- Артефакты back-office проверяемо принадлежат его репозиторию; код его `shared` не импортируется front-office.
- Ролевая видимость и рабочие действия проверяются следующими эпиками,
  указанными выше.
