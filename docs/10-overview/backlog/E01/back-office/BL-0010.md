# BL-0010 Границы клиента и HTTP-контракт

## Результат

Клиент владеет своим состоянием, представлением и HTTP-интеграцией.

## Критерии нового клиента

- Прямые импорты исходников других приложений запрещены.
- Внешние данные проверяются по актуальному OpenAPI.
- Ошибки не подтверждают невыполненное действие.
- Сохраняются code-style, размещение типов и констант и направление слоёв `app -> pages -> widgets -> features -> entities -> shared` по [техническому DoD](../../../../80-conventions/Code-Definition-of-Done-back-office.md). Старые названия экранов и компонентов не задают их новую композицию.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
