# BL-0010 Локальные маршруты, store, API-клиент и права обязательны

## Результат

Back-office содержит локальные маршруты, состояние, API-клиент, обработку ошибок и видимость по правам.

## Требуемое поведение

- Разделять очередь, доступность и меню в локальной навигации.
- Не показывать действия, которые не разрешены текущей роли.
- Проверять API-клиент back-office по снимку OpenAPI-контракта.
- Следовать [[../../../../20-architecture/Client-architecture|канонической архитектуре клиентов]]: back-office владеет своим контуром, включая локальный `shared`.

## Критерии приёмки

- Barista видит очередь и доступность, но не управление меню.
- Ошибка API не подтверждает действие в интерфейсе.
- Изменение API, не совпадающее со снимком OpenAPI, останавливает проверку клиента.
- Артефакты back-office проверяемо принадлежат его репозиторию; код его `shared` не импортируется front-office.
