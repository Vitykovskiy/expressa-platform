# BL-0004 API `/api/v1` и OpenAPI — установленный контракт

## Результат

Backend публикует versioned HTTP API /api/v1 и синхронный OpenAPI-контракт.

## Требуемое поведение

- Публиковать JSON API под /api/v1.
- Формировать OpenAPI и Swagger в local и development; отключать их в staging и production.

## Критерии приёмки

- /docs и /docs/openapi.json описывают одну актуальную версию API в local и development.
- Разрыв совместимости требует нового базового пути API.
