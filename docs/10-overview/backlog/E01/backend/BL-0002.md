# BL-0002 Валидация окружения и `.env.example` обязательны

## Результат

Каждый сервис прекращает запуск при невалидном окружении и публикует актуальный `.env.example`.

## Требуемое поведение

- Backend, front-office и back-office проверяют обязательные переменные при старте.
- Каждый сервис описывает в `.env.example` все свои переменные без секретных значений.

## Критерии приёмки

- Отсутствующая или некорректная обязательная переменная в любом сервисе даёт понятную ошибку запуска.
- `.env.example` каждого сервиса позволяет подготовить его корректное локальное окружение.
