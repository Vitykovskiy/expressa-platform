# BL-0003 PostgreSQL, миграции и чистая база

## Результат

Backend использует PostgreSQL, повторяемые миграции и чистую базу для проверяемого развёртывания.

## Требуемое поведение

- Выполнять миграции до запуска прикладного контура.
- Сохранять транзакционность создания заказа и критических переходов.

## Критерии приёмки

- Пустая PostgreSQL-база проходит миграции и seed без ручной правки.
- Полный API-маршрут до выдачи заказа работает на чистой базе.
