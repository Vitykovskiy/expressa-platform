# BL-0001 Автономный backend использует закреплённые NestJS, TypeScript и PostgreSQL

## Результат

Backend развёрнут как автономный NestJS-проект на TypeScript с PostgreSQL и собственным npm lock-файлом.

## Требуемое поведение

- Выделить самостоятельные зависимости, конфигурацию, API, тесты и документацию backend.
- Подключать PostgreSQL как единственное хранилище доменных данных.
- Закрепить LTS-версию Node и `package-lock.json` backend.
- Соблюдать модульные границы и направление слоёв из [канонической архитектуры backend](../../../../20-architecture/Backend-architecture.md).
- Содержать backend-базу знаний с `docs/README.md`, `docs/INDEX.md`, метаданными нот и разделами, соответствующими серверной ответственности.

## Критерии приёмки

- `npm ci` использует `package-lock.json` и закреплённую LTS-версию Node, затем собирает backend.
- Backend запускается без front-office и back-office и подключается к PostgreSQL.
- Границы модулей проверяемы по коду; контроллеры не содержат доменные правила стадий, цен и доступности.
- Корневой `README.md`, `docs/README.md` и `docs/INDEX.md` backend ведут к актуальным серверным нотам с обязательными метаданными.
