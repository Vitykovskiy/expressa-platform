# BL-0006 Bootstrap ролей и операционная команда управления сотрудниками

## Результат

Backend фиксирует роли `customer`, `barista`, `administrator`, создаёт первого
administrator и предоставляет операционную команду для ролей сотрудников.

## Требуемое поведение

- Идемпотентно создать initial administrator из `BOOTSTRAP_ADMIN_PHONE`.
- Предоставить операционную команду для создания сотрудника и обновления его роли
  на `barista` либо `administrator`, без UI управления сотрудниками.
- OTP принадлежат [[../../E04/backend/BL-0061|BL-0061]],
  [[../../E04/backend/BL-0062|BL-0062]] и [[../../E04/backend/BL-0063|BL-0063]].
- Runtime guard-правила принадлежат [[../../E04/backend/BL-0066|BL-0066]].

## Критерии приёмки

- `BOOTSTRAP_ADMIN_PHONE` повторяемо создаёт первого administrator.
- Операционная команда создаёт сотрудника и изменяет его роль только на `barista`
  либо `administrator`.
- Доступ staff и administrator к рабочим действиям проверяет [[../../E04/backend/BL-0066|BL-0066]].
