# BL-0006 Bootstrap ролей и операционная команда управления сотрудниками

## Результат

Backend создаёт начальные роли barista и administrator и применяет их к доступу сотрудников.

## Требуемое поведение

- Создать initial administrator из `BOOTSTRAP_ADMIN_PHONE` и проверять роли guard-правилами на защищённых маршрутах.
- Предоставить операционную команду backend для создания сотрудника и обновления ролей `barista` и `administrator`, без UI управления сотрудниками.

## Критерии приёмки

- Barista получает только разрешённые staff-действия.
- Administrator получает доступ к staff-контуру и управлению каталогом.
- `BOOTSTRAP_ADMIN_PHONE` создаёт первого administrator, а операционная команда создаёт сотрудника и изменяет только роли `barista` либо `administrator`.
