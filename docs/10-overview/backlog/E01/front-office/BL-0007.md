# BL-0007 Автономный front-office с воспроизводимой Node-сборкой

## Результат

Front-office развёрнут как автономное Vue 3, Vuetify, TypeScript и Vite PWA-приложение.

## Требуемое поведение

- Содержать собственные npm-зависимости, lock-файл, закреплённую LTS-версию Node, тему, маршруты, API-клиент, тесты и документацию.
- Поддерживать установку как PWA и работу основных функций через сеть.
- Содержать front-office-базу знаний с навигацией и нотами для клиентских областей, API-интеграции и UI.

## Критерии приёмки

- Приложение устанавливается и собирается без back-office.
- Публичное меню доступно в самостоятельном front-office.
- `npm ci` использует собственный lock-файл и закреплённую LTS-версию Node.
- Корневой `README.md`, `docs/README.md` и `docs/INDEX.md` front-office ведут к актуальным нотам с обязательными метаданными.
