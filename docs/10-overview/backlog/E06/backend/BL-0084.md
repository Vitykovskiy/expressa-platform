# BL-0084 Управление товарами следует доменной модели

Статус: superseded by [ADR-008](../../../../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md).

> Историческая задача. Модель `DRINK`/`OTHER` заменена current v3 моделью
> цены товара и `priceChoices` по ADR-008.

## Исторический результат

Administrator ведёт товары в существующих категориях.

## Историческое требуемое поведение

- При выбранной существующей категории создать, изменить, архивировать или изменить порядок товара типа `DRINK` либо `OTHER`.
- Не допускать две активные позиции товара с одинаковым порядком внутри одной категории; архивирование не меняет оформленные заказы.

## Исторические критерии приёмки

- [x] Товар сохраняет категорию, тип, название, описание, порядок и оперативную доступность.
- [x] Товар в несуществующей категории или с повторяющейся активной позицией не сохраняется.
