# BL-0087 Варианты добавок имеют цену, default и доступность

Статус: complete.

## Результат

Вариант добавки содержит цену, порядок, доступность и выбор по умолчанию.

## Требуемое поведение

- Administrator задаёт название добавки, изменение цены, порядок, оперативную доступность и признак выбора по умолчанию.
- Для обязательной группы front-office заранее выбирает бесплатные варианты по умолчанию.

## Критерии приёмки

- [x] В опубликованной обязательной группе доступен корректный набор вариантов по умолчанию.
- [x] Недоступный или платный вариант не подставляется как бесплатный выбор по умолчанию.
