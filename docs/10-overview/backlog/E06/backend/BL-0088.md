# BL-0088 Связь групп с категорией обязательна

Статус: complete.

## Результат

Группа добавок применяется к товарам одной связанной категории.

## Требуемое поведение

- Administrator связывает группу добавок с существующей категорией через API каталога.
- Применять группу только к товарам этой категории.

## Критерии приёмки

- [x] Товар связанной категории получает настройки группы добавок.
- [x] Связь с отсутствующей категорией отклоняется.
