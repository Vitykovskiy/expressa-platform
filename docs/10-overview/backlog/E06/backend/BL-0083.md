# BL-0083 Управление категориями следует API каталога

Статус: complete.

## Результат

Administrator управляет структурой категорий через back-office API.

## Требуемое поведение

- При наличии роли Administrator создать, изменить, архивировать или изменить порядок категории через `/backoffice/catalog/*`.
- Каждый endpoint `/backoffice/catalog/*` требует активной сессии Administrator; гость, Customer и Barista получают `ACCESS_DENIED`, состояние не изменяется.
- Для активных категорий сохранять уникальную позицию в меню; архивирование не меняет ранее оформленные заказы.

## Критерии приёмки

- [x] Активные категории возвращаются публичному меню в сохранённом порядке.
- [x] Вторая активная категория на той же позиции отклоняется.
