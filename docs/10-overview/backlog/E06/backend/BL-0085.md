# BL-0085 Размеры S/M/L и цены задаются доменными правилами

Статус: historical; superseded by ADR-008.

## Результат

Цена товара соответствует его типу и выбранным размерам.

## Требуемое поведение

- Для `DRINK` задать один или несколько размеров только из `S`, `M`, `L`, цену и порядок каждого размера; для `OTHER` задать одну цену без размеров.
- При открытии доступного напитка выбирать `M`, если он доступен, иначе другой доступный размер.

## Критерии приёмки

- [x] Напиток без доступного размера не публикуется.
- [x] У товара `OTHER` нет размеров, а цена задана единожды.
