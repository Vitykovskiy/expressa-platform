# BL-0090 Управление каталогом через staff API

## Результат

Administrator читает и изменяет каталог через действующий back-office API.

## Критерии нового клиента

- Используются точные методы и DTO актуального OpenAPI.
- Загрузка, подтверждённое обновление и ошибка различимы.
- Отсутствие прав не раскрывает защищённые данные и команды.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
