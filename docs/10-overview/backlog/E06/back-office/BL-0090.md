# BL-0090 Клиент управления меню следует API

## Результат

Клиент Administrator использует контракт `/backoffice/catalog/*`.

## Требуемое поведение

- При роли Administrator читать структуру и отправлять изменения каталога через API back-office.
- Показывать загрузку, успешное обновление и ошибку запроса без локального изменения контракта.

## Критерии приёмки

- Клиент не вызывает публичный endpoint для редактирования каталога.
- Ответ без прав Administrator не открывает данные или действия управления меню.
