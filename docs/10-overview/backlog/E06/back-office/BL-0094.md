# BL-0094 Редактор вариантов и цен обязателен

Статус: complete.

## Результат

Редактор размеров управляет вариантами напитка и их ценами.

## Требуемое поведение

- Для напитка выбирать используемые размеры `S`, `M`, `L`; цена и доступность задаются только выбранным размерам и независимо друг от друга.
- Сохранять хотя бы один выбранный размер. Активному напитку оставлять хотя бы один доступный размер; неактивному разрешать все выбранные размеры недоступными.
- Менять порядок выбранных размеров кнопками вверх и вниз без числового поля; новый выбранный размер добавлять в конец, а перед сохранением нормализовать порядок в `0..n-1`.
- При редактировании передавать UUID существующего размера, не передавать UUID нового и исключать снятый размер из команды для архивирования backend.

## Критерии приёмки

- [x] Редактор не предлагает размер вне `S`, `M`, `L`.
- [x] Активный напиток без доступного размера отклоняется серверной валидацией.
- [x] Последний выбранный размер нельзя снять; неактивный напиток сохраняется со всеми выбранными размерами недоступными.
- [x] Существующий размер сохраняет UUID, новый получает UUID на backend, а отсутствующий в команде размер архивируется.
- [x] Порядок размеров меняется кнопками вверх и вниз и сохраняется как последовательность `0..n-1`.
- [x] Runtime E2E проверяет критические формы на `768`, `1280` и `1440` px без горизонтального overflow и ошибок браузера.
