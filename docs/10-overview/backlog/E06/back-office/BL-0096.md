# BL-0096 Связь групп с категориями — отдельный результат

Статус: complete.

## Результат

Интерфейс отдельно назначает группы добавок категориям.

## Требуемое поведение

- При открытой категории выбрать существующие группы добавок и сохранить их связь через API каталога.
- Не подменять назначение группы редактированием товара или варианта добавки.

## Критерии приёмки

- [x] После сохранения группы доступны товарам назначенной категории.
- [x] Нельзя сохранить связь с удалённой или отсутствующей категорией.
