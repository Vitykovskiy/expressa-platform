# BL-0096 Связь групп добавок с категориями

## Результат

Administrator назначает существующие группы добавок категориям.

## Критерии нового клиента

- Связи сохраняются через действующий API каталога.
- Отсутствующая или архивированная сущность не подменяется другой.
- Назначение группы сохраняет свой предметный смысл без обязательного отдельного экрана или компонента.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
