# BL-0095 Редакторы групп и вариантов добавок обязательны

Статус: complete.

## Результат

Редакторы управляют правилами группы и её вариантами добавок.

## Требуемое поведение

- Administrator задаёт обязательность, тип выбора, минимум и максимум группы, затем ведёт её варианты с ценой, порядком, доступностью и default-признаком.
- Проверять, что опубликованная обязательная группа сохраняет допустимый доступный выбор по умолчанию.

## Критерии приёмки

- [x] В форме видны отдельные поля правил группы и свойств варианта.
- [x] Набор default-вариантов, нарушающий границы группы, не сохраняется.
