# BL-0091 Список реализует канонический рабочий сценарий

Статус: complete.

## Результат

Раздел меню показывает категории и товары для последовательного управления каталогом.

## Требуемое поведение

- После загрузки каталога показать список категорий в их порядке и товары внутри категории.
- Дать Administrator перейти к формам категории и товара, сохраняя пустое, рабочее и ошибочное состояния списка.

## Критерии приёмки

- [x] Список отражает серверный порядок категорий и товаров.
- [x] При пустом каталоге не показываются фиктивные категории или товары.
