# BL-0093 Форма редактирует товар

Статус: complete.

## Результат

Форма редактирует свойства товара по текущему контракту каталога.

## Требуемое поведение

- Форма принимает категорию, тип, название, описание, порядок и доступность товара.
- Для `DRINK` форма редактирует размеры `S`, `M`, `L` с ценой, порядком и доступностью; для `OTHER` — единую цену.

## Критерии приёмки

- [x] Форма передаёт API поля категории, типа, названия, описания, порядка и доступности.
- [x] Форма для `DRINK` сохраняет варианты размеров, а для `OTHER` — единую цену.
