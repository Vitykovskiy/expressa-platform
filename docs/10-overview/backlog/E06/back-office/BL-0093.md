# BL-0093 ProductForm редактирует товар

## Результат

ProductForm редактирует свойства товара по текущему контракту каталога.

## Требуемое поведение

- Форма принимает категорию, тип, название, описание, порядок и доступность товара.
- Для `DRINK` форма редактирует размеры `S`, `M`, `L` с ценой, порядком и доступностью; для `OTHER` — единую цену.

## Критерии приёмки

- ProductForm передаёт API поля категории, типа, названия, описания, порядка и доступности.
- ProductForm для `DRINK` сохраняет варианты размеров, а для `OTHER` — единую цену.
