# BL-0092 Изменение категории и ошибки ввода

## Результат

Administrator меняет категорию согласно действующему command DTO.

## Критерии нового клиента

- Допустимые поля и ограничения берутся из API, а не из прежней формы.
- Серверная ошибка связана с соответствующим вводом; черновик сохраняется.
- Подтверждённое сохранение отражает серверный результат.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
