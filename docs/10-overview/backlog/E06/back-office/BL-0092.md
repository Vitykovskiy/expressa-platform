# BL-0092 Форма категории показывает серверные ошибки

## Результат

Форма категории сопоставляет ошибки API с полями ввода.

## Требуемое поведение

- При создании или изменении категории отправить название, описание, порядок и признак активности.
- При ошибке валидации показать сообщение у соответствующего поля, не скрывая остальные введённые значения.

## Критерии приёмки

- Ошибка занятой активной позиции отображается в поле порядка.
- После успешного сохранения форма отражает ответ сервера.
