# BL-0097 Сквозное управление меню требует browser-доказательства

## Результат

Браузерный путь создаёт DRINK S/M/L, DRINK только S и OTHER без размера.

## Требуемое поведение

- Administrator создаёт категории, товары, цены и добавки.
- Публикует элементы и открывает меню.

## Критерии приёмки

- Каждый из трёх типов товара отображается по своим правилам.
- Публичное меню отражает активную структуру.
