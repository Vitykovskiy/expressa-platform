# BL-0073 Навигация обязана отражать права Barista/Administrator

## Результат

Back-office показывает разделы по роли сотрудника.

## Требуемое поведение

- Для barista и administrator показывать «Заказы» и «Доступность».
- Показывать «Меню» только administrator и проверять роль на сервере для защищённых действий.

## Критерии приёмки

- Barista не видит или не открывает раздел управления меню.
- Administrator видит все три раздела; обход навигации не отменяет серверную проверку роли.
