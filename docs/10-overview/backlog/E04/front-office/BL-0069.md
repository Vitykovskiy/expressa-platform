# BL-0069 Восстановление сессии и logout обязательны

## Результат

Front-office восстанавливает действующую сессию и завершает её явным выходом.

## Требуемое поведение

- После перезагрузки вызвать refresh-маршрут и восстановить текущего пользователя при действующем refresh token.
- При явном logout вызвать `/auth/logout`, отозвать refresh token и очистить корзину.

## Критерии приёмки

- Перезагрузка с действующей сессией не требует повторного ввода кода.
- После logout прежний refresh token не восстанавливает сессию.
