# BL-0067 Клиент auth следует каноническому API

## Результат

Front-office проводит телефонный вход через пять endpoint аутентификации.

## Требуемое поведение

- Экран телефона вызывает `POST /auth/otp/request`, экран кода — `POST /auth/otp/verify`; после входа клиент читает `GET /me`.
- При истечении access token вызывать `POST /auth/refresh`, а при явном выходе — `POST /auth/logout`.

## Критерии приёмки

- Клиент не смешивает запрос кода, проверку кода, обновление и выход в один endpoint.
- Ошибка любого auth-запроса показывается на соответствующем шаге без выдачи ложной сессии.
