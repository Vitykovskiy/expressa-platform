# BL-0062 Запрос OTP следует каноническому endpoint

## Результат

Код запрашивается публичным endpoint аутентификации.

## Требуемое поведение

- Гость отправляет нормализованный номер в `POST /auth/otp/request`.
- Endpoint создаёт запрос кода без требования действующей сессии.

## Критерии приёмки

- Публичный запрос корректного номера запускает отправку OTP.
- Запрос кода не использует `/auth/otp/verify`, refresh или защищённый Staff-маршрут.
