# BL-0061 Нормализация, лимиты и защита OTP обязательны

## Результат

Запрос OTP принимает российский телефон в E.164 и ограничивает злоупотребление.

## Требуемое поведение

- Привести российский номер к E.164 перед выдачей шестизначного кода; срок действия кода — пять минут, повторная отправка — через 60 секунд, попыток ввода — не более пяти.
- Для development разрешить фиксированный код только из переменной окружения.

## Критерии приёмки

- Корректный российский номер получает код, а повторный запрос раньше 60 секунд отклоняется.
- Шестая попытка, просроченный код и номер вне российского формата не подтверждаются.
