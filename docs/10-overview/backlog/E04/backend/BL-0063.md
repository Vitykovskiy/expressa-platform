# BL-0063 Отправка OTP через адаптер SMS-провайдера

## Результат

Адаптер SMS-провайдера доставляет выданный OTP на нормализованный номер.

## Требуемое поведение

- После выдачи OTP передать номер и шестизначный код в адаптер SMS-провайдера.
- Изолировать внешний вызов в адаптере, чтобы сценарий авторизации не зависел от конкретного провайдера.

## Критерии приёмки

- Корректный номер получает выданный код через настроенный адаптер.
- Ошибка провайдера не подтверждает доставку OTP.
