# BL-0064 Проверка OTP создаёт customer и сессию

## Результат

Успешная проверка OTP создаёт customer при первом входе и сессию.

## Требуемое поведение

- Гость отправляет действующий код в `POST /auth/otp/verify`; backend находит либо создаёт customer.
- В ответе создать короткоживущий access token и обновляемый refresh token для подтверждённого customer.

## Критерии приёмки

- Первый успешный код создаёт customer и действующую сессию.
- Неверный, просроченный или исчерпавший попытки код не выдаёт токены.
