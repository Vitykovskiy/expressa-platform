# BL-0045 Список, фильтры и состояния очереди определены нотами

## Результат

OrderQueueList объединяет счётчики, сортировку по времени создания, фильтр стадии, поиск номера и состояния очереди.

## Требуемое поведение

- Показать счётчики заказов и отсортировать карточки по времени создания.
- Фильтровать карточки по стадии и искать по номеру заказа.
- Показать пустую, одиночную, плотную, загрузочную и ошибочную очередь.

## Критерии приёмки

- Счётчики отражают количество заказов, а карточки выстроены по времени создания.
- Изменение фильтра и поиска обновляет видимый набор карточек.
- Пустое состояние и ошибка не смешиваются с рабочим списком.
