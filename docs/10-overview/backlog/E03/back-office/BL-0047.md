# BL-0047 Действия привязаны к допустимым переходам стадий

## Результат

OrderActionBar показывает только следующее допустимое действие сотрудника.

## Требуемое поведение

- Для каждой нетерминальной стадии показать одну основную кнопку следующего перехода.
- После действия обновить статус и скрыть недопустимые переходы.

## Критерии приёмки

- Для `Готов` доступно действие `Выдать`; для `Выдан` действия отсутствуют.
- Interaction test подтверждает последовательность `Оформлен`–`Выдан` без пропуска стадии.
