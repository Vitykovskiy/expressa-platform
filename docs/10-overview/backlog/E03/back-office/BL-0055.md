# BL-0055 Управление меню покрывает три композиции

## Результат

Storybook содержит MenuPage, CategoryEditorPage и ProductEditorPage.

## Требуемое поведение

- MenuPage показывает категории и товары, CategoryEditorPage — параметры категории, ProductEditorPage — товар и конфигурацию.
- Переход из списка открывает редактор выбранной сущности.

## Критерии приёмки

- Три композиции имеют отдельные stories с рабочими данными и ошибкой сохранения.
- Редактор товара сохраняет границу напитка с размерами и товара с одной ценой.
