# BL-0057 Interaction и accessibility — часть барьера Storybook

## Результат

Stories back-office автоматически проверяют ключевые действия и доступность.

## Требуемое поведение

- Выполнить interaction tests для поиска, фильтра, смены стадии, переключения доступности и сохранения формы.
- Проверить клавиатурный фокус, текстовые метки статусов и доступные имена элементов управления.

## Критерии приёмки

- Interaction tests проходят для действий очереди, доступности и меню.
- Автоматическая accessibility-проверка не содержит нарушений в опубликованных stories.
