# BL-0048 Доступность имеет собственные компоненты

## Результат

Каталог содержит AvailabilityRow, AvailabilityGroup и OrderIntakeControl.

## Требуемое поведение

- Показать товар, размер напитка и добавку с независимым переключателем доступности.
- Передать выбранные тип и идентификатор сущности в переключатель, отправить новое состояние на API доступности и вернуть прежнее состояние при ошибке.
- Передать текущее состояние приёма новых заказов в OrderIntakeControl; действие переключателя отправляет его новое значение на API и откатывает control при ошибке.

## Критерии приёмки

- Переключение меняет состояние только выбранной сущности.
- Ошибка сохранения восстанавливает прежнее состояние выбранной сущности или приёма заказов и показывает ошибку.
