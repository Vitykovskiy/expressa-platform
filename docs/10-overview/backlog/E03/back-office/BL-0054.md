# BL-0054 OrdersPage в Storybook back-office

## Результат

Storybook back-office содержит OrdersPage для очереди заказов.

## Требуемое поведение

- Показать пустую очередь, один заказ, плотную очередь, загрузку и ошибку.
- Объединить поиск, фильтры и карточки заказов.

## Критерии приёмки

- Пять состояний OrdersPage представлены отдельными stories.
- Поиск и фильтры меняют набор карточек.
