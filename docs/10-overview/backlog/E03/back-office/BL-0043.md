# BL-0043 Статусы должны быть различимы не только цветом

## Результат

Стадия заказа читается по тексту и форме статуса, а не только по цвету.

## Требуемое поведение

- Показать отдельные состояния `Оформлен`, `Принят`, `Готовится`, `Готов` и `Выдан`.
- Сохранить текстовую метку во всех вариантах, включая фокус и высокую плотность списка.

## Критерии приёмки

- Каждая стадия различима без цветового восприятия.
- Автоматическая проверка доступности не находит нарушений в stories статусов.
