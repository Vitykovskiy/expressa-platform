# BL-0042 Канонический набор controls определён Storybook

## Результат

Каталог содержит Button, IconButton, TextField, Select, Toggle, Tabs, SearchField и ConfirmDialog.

## Требуемое поведение

- Для каждого control показать ввод, выбор, переключение, поиск либо подтверждение по его назначению.
- Покрыть обычное, фокусное, disabled, loading и error-состояния, когда они применимы.

## Критерии приёмки

- Каждый перечисленный control имеет отдельную story с наблюдаемым результатом действия.
- Клавиатурный фокус и недоступное состояние различимы.
