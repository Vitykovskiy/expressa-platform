# BL-0058 Preview и визуальная регрессия требуются CI

## Результат

CI собирает preview Storybook и проверяет визуальные снимки back-office.

## Требуемое поведение

- Собирать и публиковать preview каталога для проверки.
- Сравнивать снимки ключевых stories на 768, 1280 и 1440 px с утверждённым эталоном.

## Критерии приёмки

- CI останавливается при неутверждённом визуальном отличии.
- Preview содержит текущие stories и доступен для продуктовой проверки.
