# BL-0059 Барьер SB-BO — самостоятельное доказательство готовности

## Результат

SB-BO допускает back-office к функциональной интеграции только после полного проверяемого каталога.

## Требуемое поведение

- Собрать полный каталог foundations, controls, orders, availability, menu, feedback и всех композиций back-office.
- Запустить interaction tests для действий смены стадий, изменения доступности и серверных ошибок форм, а также автоматическую accessibility-проверку и visual regression на согласованных viewport.
- Опубликовать preview для рабочих сценариев и получить одобрение продуктового владельца.

## Критерии приёмки

- Каталог включает все компоненты и композиции из Storybook-gates и не содержит пропусков по группам.
- Interaction tests смены стадий, доступности и серверных ошибок форм, accessibility и visual regression проходят в CI на 768, 1280 и 1440 px.
- Preview опубликован; продуктовый владелец одобрил рабочие сценарии до начала функциональной интеграции.
