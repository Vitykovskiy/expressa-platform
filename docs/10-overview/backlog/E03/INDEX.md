# E03 — исторический UI-каталог back-office

[К backlog](../INDEX.md).

Эпик относится к прежнему Admin UI. Его каталог, tokens, компоненты,
композиции и критерии подготовки удалены из актуального планирования.
Историческое завершение не доказывает готовность back-office 2.0.
Новый клиент проектируется по
[ADR-011](../../../20-architecture/ADR/ADR-011-back-office-clean-slate.md)
и [контракту продукта](../../../50-interfaces/Back-office-UI.md).
