# BL-0133 Клиент заказов следует каноническим endpoints

## Результат

Клиент заказов использует только API customer: создание, историю и детали.

## Требуемое поведение

- Использовать в клиенте front-office только `POST /orders`, `GET /orders` и `GET /orders/{id}` для создания, истории и деталей заказа.

## Критерии приёмки

- Все три действия клиента используют методы и пути API заказов.
- Ответы истории и деталей отображаются в соответствующих экранах customer.
