# BL-0135 История показывает список с пагинацией

## Результат

Экран истории показывает постраничный список заказов customer и его состояния.

## Требуемое поведение

- Отобразить номер, дату, сумму и стадию каждого заказа; по выбору открыть детали.
- Показать загрузку, пустой список, ошибку с повтором и получение следующей страницы.

## Критерии приёмки

- Пустой customer видит пустое состояние, а ошибка загрузки не маскируется пустым списком.
- Следующая страница появляется по действию пользователя и не заменяет уже показанные заказы.
