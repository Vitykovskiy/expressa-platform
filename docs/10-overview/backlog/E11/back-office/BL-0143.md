# BL-0143 Поиск позиций для изменения доступности

## Результат

Barista и Administrator находят нужную позицию и видят её доступность.

## Критерии нового клиента

- Поиск и сведения о категории помогают найти нужную сущность.
- Можно изменить доступность и приём новых заказов.
- Пользователь без staff-роли не получает защищённые данные и действия; компоновка не задана.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
