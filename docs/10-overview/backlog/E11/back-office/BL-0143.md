# BL-0143 AvailabilityPage включает категории, поиск и роли

## Результат

Страница доступности помогает Staff найти и изменить нужную позицию.

## Требуемое поведение

- Для роли Barista или Administrator сгруппировать товар, размеры и добавки по категориям, добавить поиск и переключатель intake.
- Не показывать раздел доступности пользователю без Staff-роли.

## Критерии приёмки

- Поиск находит позицию в её категории, а переключатель отображает её текущее состояние.
- Пользователь без Staff-роли не получает навигацию или действия страницы.
