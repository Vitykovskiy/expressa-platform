# BL-0144 Предварительное и подтверждённое состояние

## Результат

Оптимистичное отображение изменения не подменяет подтверждённые серверные данные.

## Критерии нового клиента

- После действия показывается предварительное значение и выполнение операции.
- При определённой ошибке восстанавливается подтверждённое состояние.
- При неизвестном исходе выполняется проверка серверного состояния, без слепого повтора изменения.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
