# BL-0144 Оптимистичное изменение откатывается при ошибке

## Результат

Неуспешное переключение возвращает на экран подтверждённое состояние.

## Требуемое поведение

- После действия Staff сразу показать новое состояние и отправить соответствующий PATCH-запрос.
- При ошибке API восстановить прежнее состояние и показать ошибку операции.

## Критерии приёмки

- При успешном ответе переключатель остаётся в новом состоянии.
- При ошибке переключатель не остаётся в неподтверждённом состоянии.
