# BL-0142 Изменение доступности через staff API

## Результат

Сотрудник меняет доступность товара, ценовой опции, добавки и приём новых заказов.

## Критерии нового клиента

- Точные endpoint и DTO берутся из текущего OpenAPI.
- Успешный результат сверяется с сервером.
- Ответ без staff-доступа не выдаётся за успешное изменение.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
