# BL-0142 Клиент доступности следует API back-office

## Результат

Клиент Staff отправляет переключения доступности по API back-office.

## Требуемое поведение

- При переключении товара, размера или добавки вызывать `PATCH /backoffice/availability/{type}/{id}`; для intake — `PATCH /backoffice/service/intake`.
- Передавать состояние API без дублирования доменной логики в клиенте.

## Критерии приёмки

- Успешный ответ обновляет показанное состояние из ответа сервера.
- Ответ без Staff-доступа не изменяет локальное состояние как успешная операция.
