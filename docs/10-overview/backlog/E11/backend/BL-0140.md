# BL-0140 Доступность добавки влияет на валидность конфигурации

## Результат

Недоступная добавка исключается из допустимой конфигурации товара.

## Требуемое поведение

- Staff изменяет доступность добавки атомарно с аудитом автора.
- Backend проверяет, что обязательные группы сохраняют корректный набор доступных вариантов по умолчанию.

## Критерии приёмки

- Следующее создание заказа с отключённой добавкой отклоняет эту конфигурацию.
- Товар не публикуется, если отключение делает default-набор обязательной группы недопустимым.
