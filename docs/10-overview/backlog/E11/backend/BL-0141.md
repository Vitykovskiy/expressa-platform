# BL-0141 Intake выключает создание, но не меню и не обработку

## Результат

Выключенный intake блокирует только новые заказы.

## Требуемое поведение

- Barista или Administrator переключает приём новых заказов через `PATCH /backoffice/service/intake`; backend сохраняет автора и время.
- Публичное меню остаётся доступным, а ранее созданные заказы продолжают обрабатываться.

## Критерии приёмки

- Новое оформление при выключенном intake получает `ORDER_INTAKE_CLOSED`.
- После включения intake новый заказ снова создаётся.
