# BL-0139 Доступность размера влияет на публикацию напитка

## Результат

Доступные размеры определяют, виден ли напиток в меню.

## Требуемое поведение

- Staff изменяет доступность конкретного размера напитка атомарно с аудитом автора.
- Backend публикует напиток, только когда у него остаётся хотя бы один доступный размер.

## Критерии приёмки

- Отключение последнего доступного размера убирает напиток из следующего публичного меню.
- Отключение одного из нескольких доступных размеров не скрывает напиток.
