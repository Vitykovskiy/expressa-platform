# BL-0147 Измеряются канонические performance, индексы и отсутствие N+1

## Результат

Производительность backend подтверждена для меню, заказа, очереди и базы данных.

## Требуемое поведение

- Измерить p95 публичного меню, операций заказа и отсутствие N+1 на целевом наборе данных.
- Проверить индексы меню, очереди, истории и аудита.

## Критерии приёмки

- p95 меню не превышает 500 мс, операций заказа — 700 мс.
- N+1-запросов нет, необходимые индексы подтверждены.
