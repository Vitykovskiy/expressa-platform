# BL-0160 Репетиция миграции входит в release-verification

## Результат

Репетиция миграции подтверждает применимость миграций на совместимом выпуске.

## Требуемое поведение

- Применить повторяемые миграции к чистой и рабочей тестовой базе.
- Проверить health и API smoke после миграции.

## Критерии приёмки

- Миграции завершаются без ручной корректировки данных.
- После миграции health и smoke проходят.
