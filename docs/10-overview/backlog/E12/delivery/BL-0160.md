# BL-0160 Репетиция миграции входит в release-verification

## Результат

Репетиция миграции подтверждает применимость миграций на репрезентативной
рабочей базе совместимого выпуска.

## Требуемое поведение

- Применить миграции к репрезентативной рабочей тестовой базе.
- Проверить health и API smoke после миграции.

## Критерии приёмки

- Миграции завершаются без ручной корректировки репрезентативных данных.
- После миграции health и API smoke проходят.
