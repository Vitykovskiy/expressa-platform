# BL-0157 Ежедневный шифрованный backup и alert каноничны

## Результат

PostgreSQL получает ежедневную шифрованную резервную копию с контролем выполнения и хранением.

## Требуемое поведение

- Запланировать ежедневное создание шифрованной копии.
- Контролировать выполнение и применять политику хранения.

## Критерии приёмки

- За каждый день есть шифрованная резервная копия и результат её выполнения.
- Наблюдаемость включает сигнал о резервных копиях.
