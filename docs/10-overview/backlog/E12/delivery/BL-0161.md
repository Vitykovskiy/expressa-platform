# BL-0161 Release candidate использует независимые версии и staging

## Результат

Release candidate фиксирует независимые версии, теги, changelog и staging-набор образов.

## Требуемое поведение

- Сопоставить package.json, vX.Y.Z и CHANGELOG.md каждого сервиса.
- Развернуть в staging immutable образы и записать их идентификаторы.

## Критерии приёмки

- Несовпадение версии, тега или changelog блокирует выпуск.
- Staging содержит точные версии backend, front-office и back-office.
