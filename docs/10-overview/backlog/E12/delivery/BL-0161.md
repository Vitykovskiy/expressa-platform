# BL-0161 Production promotion использует точные staging digest

## Результат

После приёмки MVP оператор вручную продвигает в production совместимый staging-набор.

## Требуемое поведение

- Принять только зафиксированные digest backend, front-office и back-office
  из прошедшего staging-набора.
- Развернуть в production ровно эти образы без повторной сборки и `latest`.

## Критерии приёмки

- Promotion требует явного ручного запуска после приёмки MVP.
- Production использует три точных staging digest и не принимает иной образ,
  повторную сборку или `latest`.
