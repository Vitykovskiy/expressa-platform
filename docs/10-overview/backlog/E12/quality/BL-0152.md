# BL-0152 Ручная приёмка пользовательских потоков входит в поставку

## Результат

Пользовательские потоки принимаются вручную в работающем приложении; отдельный E2E-набор не поддерживается.

## Требуемое поведение

- Проверить нужные пользовательские потоки вручную на поставляемом development-окружении.

## Критерии приёмки

- Ручная приёмка выполнена для поставляемого development-окружения.
