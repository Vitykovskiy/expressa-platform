# BL-0152 Результат Q-E2E входит в нормативную приёмку выпуска

## Результат

Нормативная приёмка выпуска использует успешный Q-E2E из [BL-0170](../../E13/quality/BL-0170.md) как проверяемое доказательство.

## Требуемое поведение

- Запустить Q-E2E на подготовленном совместимом наборе версий front-office, back-office и backend.
- Сохранить результат запуска вместе с другими доказательствами release-приёмки.

## Критерии приёмки

- Q-E2E из [BL-0170](../../E13/quality/BL-0170.md) успешно пройден на принимаемом наборе версий.
- Доказательство запуска однозначно связано с принимаемыми версиями трёх приложений.
