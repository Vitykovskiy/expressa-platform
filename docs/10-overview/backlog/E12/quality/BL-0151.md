# BL-0151 Q-SMOKE — самостоятельный сквозной API результат

## Результат

Q-SMOKE подтверждает чистую базу, миграции, seed и полный API-маршрут до выдачи.

## Требуемое поведение

- Поднять чистую PostgreSQL-базу, применить миграции и seed.
- Пройти API-цепочку создания и выдачи заказа.

## Критерии приёмки

- Миграции и seed завершаются без ручной правки.
- Заказ проходит до «Выдан» на чистой базе.
