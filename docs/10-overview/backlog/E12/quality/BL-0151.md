# BL-0151 Q-SMOKE — самостоятельный сквозной API результат

## Результат

Q-SMOKE использует проверенно инициализированную чистую базу и подтверждает
API-цепочку заказа до выдачи.

## Требуемое поведение

- Использовать чистую базу после миграций и idempotent seed из
  [BL-0003](../../E01/backend/BL-0003.md).
- Пройти API-цепочку создания заказа до `ISSUED`.

## Критерии приёмки

- Заказ проходит от создания до `ISSUED` на проверенно инициализированной базе.
