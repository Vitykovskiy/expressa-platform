# BL-0153 WCAG-проверка соответствует канонической тестовой стратегии

## Результат

Основные маршруты front-office соответствуют WCAG 2.1 AA. Граница back-office
зафиксирована в [ADR-010](../../../../20-architecture/ADR/ADR-010-back-office-interaction-boundary.md).

## Требуемое поведение

- Проверить клавиатуру, видимый фокус, подписи, контраст, текстовые статусы и мобильные зоны front-office.
- Провести ручную проверку; автоматизированные тесты запускать только после приёмки и отдельного прямого запроса пользователя.

## Критерии приёмки

- Основные маршруты front-office проходят WCAG 2.1 AA.
- Мобильные интерактивные зоны не меньше 44×44 px.
