# BL-0149 Производительность front-office следует целевым метрикам

## Результат

Front-office укладывается в целевой производительный бюджет на мобильном устройстве.

## Требуемое поведение

- Измерить основной JavaScript после сжатия и отзывчивость основных маршрутов.
- Не включать в основной JavaScript необязательные ресурсы.

## Критерии приёмки

- Основной JavaScript после сжатия не превышает 300 КБ.
- Маршруты меню, корзины и заказа отзывчивы на целевом мобильном устройстве.
