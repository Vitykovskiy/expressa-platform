# BL-0106 Оформление требует customer-сессии

Статус: complete.

## Результат

Подтверждать оформление может только customer с подтверждённым номером.

## Требуемое поведение

- Направить гостя с корзиной в телефонную авторизацию через безопасный внутренний `returnTo` на подтверждение оформления; после успешного OTP вернуть customer к этому экрану с сохранённой корзиной.
- [`POST /api/v1/orders`](../../../../50-interfaces/Orders-API.md) принимает только активную customer-сессию; backend получает customer из сессии до начала транзакции.
- Для гостя, barista и administrator backend возвращает [`ACCESS_DENIED`](../../../../50-interfaces/Error-model-and-idempotency.md), заказ не создаётся.

## Критерии приёмки

- [x] Гость не создаёт заказ до подтверждения номера телефона.
- [x] После успешного OTP customer возвращается к подтверждению с сохранённой корзиной.
- [x] Заказ создаётся только для customer; guest, barista и administrator не создают заказ.
