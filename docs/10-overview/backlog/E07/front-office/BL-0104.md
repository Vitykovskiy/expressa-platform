# BL-0104 Добавление использует валидную конфигурацию товара

Статус: complete.

## Результат

Карточка добавляет в корзину только опубликованный доступный товар с допустимой конфигурацией.

## Требуемое поведение

- Для напитка выбрать доступный `M`, иначе другой доступный размер; для товара без размеров не показывать выбор размера.
- Предвыбрать варианты обязательных групп и блокировать добавление при нарушении их минимумов, максимумов или правил выбора.

## Критерии приёмки

- [x] Кнопка добавления доступна сразу для опубликованной доступной позиции с корректными значениями по умолчанию.
- [x] Нельзя добавить конфигурацию с недопустимым размером или набором добавок.
