# BL-0107 Клиент передаёт Idempotency-Key

Статус: complete.

## Результат

Одна попытка оформления использует стабильный ключ идемпотентности до получения результата.

## Требуемое поведение

- Создать ключ перед отправкой `POST /api/v1/orders` и вложить его в заголовок `Idempotency-Key`.
- При повторе отправить тот же ключ, а для следующего оформления создать новый.

## Критерии приёмки

- [x] Повтор после сетевой ошибки возвращает первоначальный заказ без второй записи.
- [x] Новое подтверждённое оформление не использует ключ предыдущего заказа.
