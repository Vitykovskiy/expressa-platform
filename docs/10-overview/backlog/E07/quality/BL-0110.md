# BL-0110 Обязательный browser checkout — отдельное доказательство

## Результат

Браузерный сценарий checkout подтверждает revalidation, OTP, идемпотентное создание и открытие текущего заказа.

## Требуемое поведение

- Собрать корзину, изменить цену либо доступность перед оформлением и пройти OTP.
- Повторить отправку создания с тем же Idempotency-Key.

## Критерии приёмки

- Изменённый итог требует подтверждения, недоступная позиция не создаёт заказ.
- Повторная отправка с тем же ключом не создаёт второй заказ.
