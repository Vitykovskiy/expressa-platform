# BL-0110 Обязательный browser checkout — отдельное доказательство

Статус: complete.

## Результат

Браузерный сценарий checkout подтверждает revalidation, OTP, идемпотентное создание и открытие текущего заказа.

## Требуемое поведение

- Проверить шесть browser-сценариев: гостевой checkout через OTP, изменение цены, недоступность варианта, закрытый приём, потерю ответа и адаптивность.
- Повторить отправку создания с тем же `Idempotency-Key` и проверить отдельный ключ следующего оформления.

## Критерии приёмки

- [x] Изменённый итог требует подтверждения, недоступная позиция и закрытый приём не создают заказ.
- [x] Повторная отправка с тем же ключом не создаёт второй заказ.
- [x] Корзина и созданный заказ проверены на `320`, `390`, `479`, `480`, `767`, `768`, `1023`, `1024`, `1280` и `1440` px без overflow, перекрытий и новых ошибок консоли.
