# BL-0100 Номер заказа — наблюдаемый доменный результат

Статус: complete.

## Результат

Каждому созданному заказу присваивается человекочитаемый номер формата `YYYYMMDD-NNN`.

## Требуемое поведение

- Присваивать номер при успешном создании заказа по календарному дню UTC.
- Возвращать номер в ответе создания и хранить его вместе с заказом.

## Критерии приёмки

- [x] Номер нового заказа соответствует формату `YYYYMMDD-NNN` и суточная последовательность атомарна.
- [x] Ответ создания и сохранённая запись содержат один и тот же номер.
