# BL-0100 Номер заказа — наблюдаемый доменный результат

## Результат

Каждому созданному заказу присваивается человекочитаемый номер формата `YYYYMMDD-NNN`.

## Требуемое поведение

- Присваивать номер при успешном создании заказа.
- Показывать тот же номер в ответе создания, истории и деталях.

## Критерии приёмки

- Номер нового заказа соответствует формату `YYYYMMDD-NNN`.
- Номер неизменен во всех последующих чтениях этого заказа.
