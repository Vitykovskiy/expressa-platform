# BL-0101 Создание заказа идемпотентно по HTTP-соглашению

Статус: complete.

## Результат

Повтор создания с одним `Idempotency-Key` возвращает первоначальный заказ без дубля.

## Требуемое поведение

- Клиент передаёт `Idempotency-Key` в `POST /api/v1/orders`.
- Сервер сопоставляет повторный запрос с уже созданным заказом по ключу.

## Критерии приёмки

- [x] Два одинаковых запроса одного customer с одним ключом возвращают один идентификатор заказа.
- [x] Повтор не создаёт второй заказ и не меняет его снимок; другое тело с тем же ключом отклоняется.
