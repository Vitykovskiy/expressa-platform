# BL-0101 Создание заказа идемпотентно по HTTP-соглашению

## Результат

Повтор создания с одним `Idempotency-Key` возвращает первоначальный заказ без дубля.

## Требуемое поведение

- Клиент передаёт `Idempotency-Key` в `POST /orders`.
- Сервер сопоставляет повторный запрос с уже созданным заказом по ключу.

## Критерии приёмки

- Два одинаковых запроса с одним ключом возвращают один идентификатор заказа.
- Повтор не создаёт второй заказ и не меняет его снимок.
