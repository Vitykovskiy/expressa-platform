# BL-0099 Сервер повторно проверяет цену, конфигурацию и доступность

Статус: complete.

## Результат

Заказ создаётся только из актуальной допустимой конфигурации по серверному расчёту.

## Требуемое поведение

- Перед созданием сверить товары, размеры, добавки, количество, цены и приём новых заказов с текущим меню.
- Вернуть `ORDER_TOTAL_CHANGED` при изменении итоговой суммы, `MENU_ITEM_UNAVAILABLE` при недоступной позиции, `ORDER_INTAKE_CLOSED` при закрытом приёме и `VALIDATION_ERROR` при недопустимой конфигурации.

## Критерии приёмки

- [x] Переданная клиентом сумма не определяет итог заказа.
- [x] Недоступная позиция, неверная конфигурация или закрытый приём не создают заказ и возвращают релевантный код ошибки.
