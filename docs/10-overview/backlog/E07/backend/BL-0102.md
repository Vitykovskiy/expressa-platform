# BL-0102 Коды актуализации следуют общей модели ошибок

Статус: complete.

## Результат

Корзина получает единые коды актуализации перед оформлением.

## Требуемое поведение

- При новой сумме вернуть `ORDER_TOTAL_CHANGED`.
- При выключенной позиции вернуть `MENU_ITEM_UNAVAILABLE`; при закрытом приёме — `ORDER_INTAKE_CLOSED`.

## Критерии приёмки

- [x] Код ошибки определяет единственную причину отказа и доступен клиенту в общем формате ошибок.
- [x] Клиент может показать новый итог либо затронутую позицию без разбора текста сообщения.
