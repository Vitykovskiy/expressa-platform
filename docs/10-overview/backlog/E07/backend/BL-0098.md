# BL-0098 Доменная модель фиксирует заказ и его снимки

Статус: superseded by [ADR-008](../../../../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md).

> Историческая задача. Её v2-модель снимка с размером заменена current v3
> контрактом `priceChoiceId`/`portionLabel` в ADR-008.

## Исторический результат

Созданный заказ хранит независимый снимок состава и итоговой суммы в одной
транзакции.

## Историческое требуемое поведение

- При `POST /api/v2/orders` сформировать заказ со снимками названий, цен, добавок, количества и размера напитка.
- В одной транзакции сохранить заказ и снимки позиций.
- Изменения меню после оформления не изменяют сохранённый состав заказа.

## Исторические критерии приёмки

- [x] Ответ создания содержит номер, начальную стадию `CREATED`, итог в целых рублях и снимок позиций.
- [x] Изменение товара или добавки в меню не меняет сохранённый снимок ранее созданного заказа.
- [x] Ошибка сохранения снимка откатывает создание заказа.
