# BL-0098 Доменная модель фиксирует заказ и его снимки

Статус: complete.

## Результат

Созданный заказ хранит независимый снимок состава и итоговой суммы в одной
транзакции.

## Требуемое поведение

- При `POST /api/v1/orders` сформировать заказ со снимками названий, цен, добавок, количества и размера напитка.
- В одной транзакции сохранить заказ и снимки позиций.
- Изменения меню после оформления не изменяют сохранённый состав заказа.

## Критерии приёмки

- [x] Ответ создания содержит номер, начальную стадию `CREATED`, итог в копейках и снимок позиций.
- [x] Изменение товара или добавки в меню не меняет сохранённый снимок ранее созданного заказа.
- [x] Ошибка сохранения снимка откатывает создание заказа.
