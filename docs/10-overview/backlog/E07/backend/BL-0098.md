# BL-0098 Доменная модель фиксирует заказ и его снимки

## Результат

Созданный заказ хранит независимый снимок состава и итоговой суммы.

## Требуемое поведение

- При `POST /orders` сформировать заказ со снимками названий, цен, добавок, количества и размера напитка.
- Изменения меню после оформления не изменяют сохранённый состав заказа.

## Критерии приёмки

- Ответ создания содержит номер, начальную стадию `Оформлен`, итог в копейках и снимок позиций.
- Изменение товара или добавки в меню не меняет детали ранее созданного заказа.
