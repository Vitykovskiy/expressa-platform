# BL-0081 Сохранение позиции возврата задано UI-нотой

## Результат

Возврат из карточки товара восстанавливает позицию прокрутки меню.

## Требуемое поведение

- Перед открытием ProductSheet сохранить текущую позицию прокрутки списка меню.
- При закрытии карточки восстановить сохранённую позицию, а не прокручивать каталог к началу.

## Критерии приёмки

- После возврата пользователь видит тот же участок каталога, с которого открыл карточку.
- Если сохранённой позиции нет, меню открывается в штатной начальной позиции.
