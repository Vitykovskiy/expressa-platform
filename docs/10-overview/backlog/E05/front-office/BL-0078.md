# BL-0078 Клиент читает публичное меню по каноническому контракту

## Результат

Клиент получает меню и состояние приёма заказов из `GET /public/menu`.

## Требуемое поведение

- API-клиент запрашивает `GET /public/menu` и преобразует ответ в модель меню без вычисления UI-состояний экрана.
- Маппинг сохраняет категории, товары, размеры, добавки, их доступность и metadata default.

## Критерии приёмки

- Некорректный либо неполный ответ не преобразуется в доменную модель меню; экранные состояния остаются ответственностью MenuPage.
- Успешный маппинг не создаёт загрузочное, пустое либо ошибочное состояние экрана.
