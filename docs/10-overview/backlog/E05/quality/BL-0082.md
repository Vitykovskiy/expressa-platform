# BL-0082 Обязательный браузерный путь меню требует доказательства

Статус: superseded by [ADR-008](../../../../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md).

> Историческая задача. Сценарии S/M/L и `OTHER` заменены current v3
> конфигурацией цены товара и `priceChoices` по ADR-008.

## Исторический результат

Браузерный путь меню проверяет S/M/L, только S, OTHER без размеров и бесплатные добавки по умолчанию.

## Историческое требуемое поведение

- Открыть каждый тип товара и изменить конфигурацию.
- Добавить позицию в корзину и сверить итог.

## Исторические критерии приёмки

- M либо другой доступный размер выбран автоматически.
- Бесплатные варианты выбраны во всех обязательных группах.
