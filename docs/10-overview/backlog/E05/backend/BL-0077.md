# BL-0077 `GET /public/menu` — установленный агрегат

## Результат

`GET /public/menu` возвращает публичное меню и состояние приёма новых заказов.

## Требуемое поведение

- По публичному запросу собрать активные категории в заданном порядке и доступные для публикации товары с их размерами, ценами и добавками.
- Включить в ответ состояние приёма новых заказов и metadata доступности, размеров и вариантов добавок.
- Сортировать товары внутри категории, группы добавок и варианты добавок по их `sort_order`.
- Требовать `sort_order` для отображаемых Category, Product, ProductVariant, CategoryModifierGroup и ModifierOption; порядок Category уникален среди активных категорий, Product — внутри категории, а размер ProductVariant уникален внутри напитка.

## Критерии приёмки

- Ответ не содержит неактивную категорию, непубликуемый товар или недоступную конфигурацию обязательных добавок.
- При выключенном приёме заказов список меню остаётся доступен, а состояние приёма передаётся отдельно.
- Отсутствующий `sort_order` отклоняется валидацией; API не применяет запасной порядок.
