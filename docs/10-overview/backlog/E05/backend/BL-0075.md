# BL-0075 Схема соответствует канонической доменной модели

## Результат

Схема каталога хранит Category, Product, ProductVariant, ModifierGroup, ModifierOption и CategoryModifierGroup по доменной модели.

## Требуемое поведение

- Задать у категории порядок и активность; у товара — тип `DRINK` или `OTHER`, доступность и категорию; у напитка — размеры `S`, `M`, `L`, у `OTHER` — единую цену; у групп добавок — обязательность, тип выбора, минимум и максимум.
- Для каждого размера хранить цену, порядок и оперативную доступность; для варианта добавки — название, изменение цены, порядок, доступность и признак выбора по умолчанию.
- Связь CategoryModifierGroup хранит категорию, группу и её `sort_order`; Category и Product хранят обязательные идентификаторы, название, описание, порядок, активность и архивирование.

## Критерии приёмки

- Схема не допускает цену без соответствующего типа товара, размеры у `OTHER` и конфигурацию группы без границ выбора.
- Категория без названия, товара без названия или типа, а также добавка без цены-изменения не проходят валидацию.
- ProductVariant без продукта, ModifierOption без группы или CategoryModifierGroup без обеих сторон не сохраняются.
