# BL-0076 Правила публикации, размеров и defaults заданы нотами

## Результат

Правила публикации и начального выбора следуют доменной ноте каталога.

## Требуемое поведение

- Backend публикует напиток только при доступном размере, любой товар — только при корректном наборе доступных добавок по умолчанию в обязательных группах.
- Ответ меню передаёт оперативную доступность и признак варианта по умолчанию, не вычисляя выбор размера на стороне backend.
- Валидировать `min_select ≤ max_select`, для `single` требовать `max_select = 1`, для обязательной группы — `min_select ≥ 1`; доступные бесплатные defaults должны укладываться в эти границы.
- Хранить цены товара, размера и добавки целыми копейками; размеры уникальны внутри напитка, `DRINK` имеет размеры, а `OTHER` — одну цену без размеров.

## Критерии приёмки

- Товар с недоступными размерами или некорректными обязательными добавками не попадает в публичное меню; metadata доступности и default остаются доступны для клиента.
- Ответ не назначает размер `M` как выбранный: это решение остаётся в ProductSheet.
- Недоступность размера применяется только к варианту `DRINK`; `OTHER` не получает размер и не проходит проверку доступности размера.
- Конфигурация с дробной суммой, повторным размером либо default вне границ выбора отклоняется до публикации.
