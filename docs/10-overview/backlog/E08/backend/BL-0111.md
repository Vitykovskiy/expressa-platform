# BL-0111 Допустимые стадии определены lifecycle-нотой

## Результат

Контур приготовления допускает только последовательность `CREATED` → `ACCEPTED` → `PREPARING` → `READY`.

## Требуемое поведение

- При создании назначать `CREATED`; разрешать только переходы `CREATED` → `ACCEPTED` → `PREPARING` → `READY`.
- Перед изменением проверить, что заказ существует и текущая стадия соответствует ожидаемому началу перехода.

## Критерии приёмки

- Нельзя пропустить подготовительную стадию или выполнить обратный переход.
- В ответе деталей возвращается фактическая текущая стадия заказа.
