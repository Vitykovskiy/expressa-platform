# BL-0113 Очередь staff следует API back-office

## Результат

Очередь staff получает заказы через `GET /backoffice/orders`.

## Требуемое поведение

- Запрашивать очередь для сотрудника с фильтром по стадии и поиском по номеру заказа.
- Сортировать полученную очередь по времени создания и выводить только доступные staff-заказы.

## Критерии приёмки

- В очереди отображаются номер, время, сумма и стадия; customer не получает staff-маршрут.
- Пустой результат фильтра не заменяется заказами другой стадии.
