# BL-0112 Критические переходы создают OrderEvent

## Результат

Каждый подготовительный переход заказа сохраняет событие с автором, временем, предыдущей и новой стадиями.

## Требуемое поведение

- В одной транзакции изменить одну из стадий `CREATED` → `ACCEPTED` → `PREPARING` → `READY` и создать OrderEvent.
- Записать автора, время, предыдущую и новую стадии в одном событии.

## Критерии приёмки

- В деталях заказа виден журнал переходов; отклонённый переход не создаёт событие.
- Событие не может содержать одинаковые предыдущую и новую стадии.
- Ошибка записи события откатывает транзакцию: стадия заказа остаётся прежней.
