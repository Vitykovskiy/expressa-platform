# BL-0120 Обновление очереди не реже пяти секунд

## Результат

Активная очередь опрашивает API с интервалом не более пяти секунд.

## Критерии нового клиента

- Используется точный endpoint актуального OpenAPI.
- Обновление сохраняет поиск по номеру и выбранную стадию.
- Фоновое чтение не подменяет подтверждённые данные результатом устаревшего запроса.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
