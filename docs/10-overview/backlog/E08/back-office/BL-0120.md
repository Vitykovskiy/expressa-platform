# BL-0120 Polling очереди back-office не реже одного запроса в пять секунд

## Результат

Очередь back-office обновляется polling не реже одного запроса в пять секунд.

## Требуемое поведение

- Пока открыт экран очереди, запрашивать `GET /backoffice/orders` не реже одного раза в пять секунд, передавая текущий поиск по номеру и фильтр по стадии.
- После каждого ответа сохранять введённый номер и выбранную стадию.

## Критерии приёмки

- Интервал активного опроса не превышает пяти секунд.
- Обновление очереди не меняет поиск по номеру и фильтр по стадии.
