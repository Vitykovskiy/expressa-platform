# BL-0121 Понятные ошибки API и восстановление

## Результат

Ошибка API даёт сотруднику понятное последствие и одно полезное действие восстановления.

## Критерии нового клиента

- VALIDATION_ERROR связывается с соответствующим вводом по details.
- Технические code/message/requestId не заменяют обычное объяснение; диагностика сохраняется в техническом канале.
- Ошибка без field details не связывается с произвольным полем и не выглядит успешной операцией.

Это требования результата, без утверждения о готовности реализации.
Прежние визуальные критерии и отметки приёмки не применяются к версии 2.0.
