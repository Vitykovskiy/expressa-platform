# BL-0121 Back-office единообразно показывает документированную общую обработку ошибок API

## Результат

Back-office выводит ошибки API через единый объект `{ code, message, details, requestId }`.

## Требуемое поведение

- Для ошибки очереди, формы или действия показать `code`, `message` и `requestId` в подходящем состоянии экрана или поля формы.
- При `VALIDATION_ERROR` сопоставить `details` с соответствующими полями формы; прочие ошибки показать в состоянии экрана либо действия.

## Критерии приёмки

- `VALIDATION_ERROR`, `ACCESS_DENIED` и `RESOURCE_ARCHIVED` отображаются общей моделью; ошибка не выглядит успешным сохранением.
- Ошибка без field details не подсвечивает произвольное поле и сохраняет `requestId` для диагностики.
