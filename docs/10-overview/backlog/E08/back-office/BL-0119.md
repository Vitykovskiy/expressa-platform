# BL-0119 Принят — действие единой карточки переходов

## Результат

Карточка заказа показывает одно основное действие, соответствующее текущей стадии.

## Требуемое поведение

- Для `CREATED` вызвать `POST /backoffice/orders/{id}/accept`, для `ACCEPTED` — `POST /backoffice/orders/{id}/start-preparing`, для `PREPARING` — `POST /backoffice/orders/{id}/mark-ready`.
- Для каждого действия показать рабочее, загрузочное и ошибочное состояния в Storybook.

## Критерии приёмки

- При успехе заказ получает соответственно `ACCEPTED`, `PREPARING` либо `READY`; повторное действие из другой стадии недоступно.
- Ошибка перехода сохраняет текущую карточку и не показывает следующий этап как выполненный.
