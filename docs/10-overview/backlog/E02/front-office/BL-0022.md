# BL-0022 Контролы и состояния определены каноническим каталогом

## Результат

Каталог Storybook содержит Button, IconButton, TextField, PhoneField, OtpInput, Checkbox, Radio, Chip и QuantityStepper с применимыми состояниями.

## Требуемое поведение

- Для каждого контрола показать базовое, интерактивное, фокусируемое с клавиатуры, загрузочное и ошибочное состояния, когда они применимы.
- Для Button, TextField, Checkbox, Radio, Chip и QuantityStepper задать доступные интеракции и граничные состояния ввода.

## Критерии приёмки

- Storybook показывает перечисленные контролы и их применимые состояния на 320, 390 и 768 px.
- Контрол без применимого состояния не получает фиктивный сценарий; фокус клавиатуры остаётся видимым.
