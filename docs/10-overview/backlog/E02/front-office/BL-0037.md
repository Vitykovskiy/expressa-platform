# BL-0037 Interaction и accessibility — часть барьера Storybook

## Результат

Истории front-office содержат интеракционные проверки и автоматическую проверку доступности.

## Требуемое поведение

- Для каждого применимого компонента и композиции добавить интеракционный сценарий и автоматическую проверку доступности, включая фокус клавиатуры.
- Выполнять сценарий на опубликованной истории без зависимости от ручной проверки.

## Критерии приёмки

- Барьер не проходит, если интеракционный сценарий или автоматическая проверка доступности завершается ошибкой.
- Ошибка accessibility либо interaction не заменяется успешным визуальным снимком.
