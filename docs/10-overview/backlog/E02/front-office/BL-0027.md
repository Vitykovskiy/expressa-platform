# BL-0027 Количество и цена — компоненты каталога

## Результат

QuantityStepper и PriceLabel показывают количество позиции и её пересчитанную цену.

## Требуемое поведение

- Показать изменение количества и динамическую цену для товара с большой суммой в обычном и фокусируемом с клавиатуры состояниях.
- Проверить нижнюю и верхнюю доступные границы счётчика без отрицательного количества.
- Получать максимальное количество одной конфигурации из серверной настройки; при отсутствии значения применять 20.

## Критерии приёмки

- После изменения количества история показывает обновлённую цену и остаётся читаемой на 320, 390 и 768 px.
- Нажатие недоступного уменьшения не изменяет количество и итог.
- Количество выше серверного лимита не принимается, а значение по умолчанию ограничено 20.
