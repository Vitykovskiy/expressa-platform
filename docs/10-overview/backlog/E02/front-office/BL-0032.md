# BL-0032 Общие feedback-состояния определены канонически

## Результат

Storybook содержит Skeleton, EmptyState, ErrorState, InlineError, Snackbar, Dialog и NotificationPermission.

## Требуемое поведение

- Для общих состояний показать загрузку, пустой результат, ошибку, встроенную ошибку, уведомление, диалог и разрешение уведомлений.
- Проверить закрытие диалога и уведомления без ошибочного подтверждения действия.

## Критерии приёмки

- Состояния доступны с клавиатуры и читаемы на 320, 390 и 768 px; ошибка не выглядит успешным действием.
- Запрет уведомлений не блокирует остальные сценарии интерфейса.
