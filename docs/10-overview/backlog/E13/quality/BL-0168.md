# BL-0168 Staff готовит, принимает оплату и выдаёт заказ

## Результат

Независимый браузерный сценарий подтверждает обработку customer-заказа сотрудником до выдачи после оплаты.

## Требуемое поведение

- После [[BL-0167|BL-0167]] создать собственный заказ через готовые fixtures/POM и войти как сотрудник.
- Найти заказ в back-office и провести его через `CREATED`, `ACCEPTED`, `PREPARING`, `READY` и `ISSUED`.
- После получения оплаты на кассе выполнить действие «Выдать заказ» и проверить наблюдаемый результат каждого перехода.
- Использовать только UI подготовленных приложений; заказ получает уникальные данные сценария.

## Критерии приёмки

- Сотрудник видит созданный заказ и последовательно переводит его во все обязательные стадии.
- Действие «Выдать заказ» переводит заказ из `READY` в `ISSUED`; отдельное состояние оплаты не требуется.
- Spec не содержит прямых локаторов, технических ожиданий или обхода UI.
