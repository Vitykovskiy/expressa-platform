# BL-0165 Основа POM, fixtures и тестовых данных Q-E2E

## Результат

Standalone E2E-набор предоставляет минимальную основу для независимых UI-only сценариев с Page Object Model.

## Требуемое поведение

- Проверять URL подготовленных front-office и back-office, учётные данные ролей и OTP из окружения до начала сценария.
- Предоставлять `test`, `expect` и Page/Component Objects через единую точку `fixtures/test.ts`.
- Формировать уникальные предметные данные для каждого сценария без глобального изменяемого состояния.
- Соблюдать структуру POM и UI-only границы текущего E2E DoD без общего `BasePage`, DSL и абстракций на будущее.

## Критерии приёмки

- Ошибка обязательной конфигурации останавливает запуск до пользовательских действий и называет отсутствующий вход.
- Spec не создаёт локаторы и не импортирует Page/Component Objects напрямую.
- Статические проверки standalone E2E из Definition of Done проходят.
