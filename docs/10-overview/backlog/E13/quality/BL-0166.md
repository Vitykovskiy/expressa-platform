# BL-0166 Administrator создаёт и публикует меню через UI

## Результат

Независимый браузерный сценарий подтверждает, что administrator публикует собираемый товар, видимый customer в public menu.

## Требуемое поведение

- После [[BL-0165|BL-0165]] войти как administrator и через back-office создать категорию, товар, варианты, добавки и цены.
- Повторно открыть созданные сущности и проверить сохранённые значения через предметные методы POM.
- Открыть front-office и проверить опубликованные категорию, товар, конфигурацию и цену.
- Удалить или архивировать созданные каталоговые данные через UI и проверить их отсутствие.

## Критерии приёмки

- Сценарий использует собственные уникальные данные и не зависит от порядка запуска.
- Повторное открытие подтверждает сохранение, public menu — публикацию, финальная проверка — UI-cleanup.
- Spec содержит только пользовательские шаги и публичные методы fixtures/POM.
