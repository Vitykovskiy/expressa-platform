# Expressa MVP — техническое задание

**Версия:** 2.0  
**Дата:** 24 июля 2026 года  
**Статус:** готово к оценке и реализации  
**Назначение:** каноническое продуктовое и техническое основание для трёх автономных репозиториев Expressa

## 1. Основание и цель

Expressa — два устанавливаемых прогрессивных веб-приложения (PWA): мобильное приложение для оформления заказа в кофейне-киоске и рабочее приложение для сотрудников.

MVP обеспечивает полный контур:

1. клиент просматривает меню;
2. клиент проходит телефонную авторизацию;
3. клиент формирует корзину и оформляет заказ;
4. бариста принимает заказ, готовит его и отмечает готовность к выдаче;
5. клиент оплачивает заказ на кассе при получении;
6. после получения оплаты сотрудник выдаёт заказ;
7. клиент видит состояние и историю собственных заказов;
8. администратор управляет меню, ценами и доступностью.

## 2. Зафиксированные организационные решения

### 2.2. Управление пакетами

Во всех репозиториях применяется `npm`.

Обязательные артефакты:

- `package.json`;
- `package-lock.json`;
- фиксированная LTS-версия Node.js;
- команды `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`;
- проверка целостности lock-файла в CI.
