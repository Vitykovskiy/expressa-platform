# Роли и доступ

Матрица задаёт требуемый доступ, не подтверждает реализацию. По
[ADR-017](../20-architecture/ADR/ADR-017-account-memberships-and-session-context.md)
один аккаунт имеет независимые customer/employee-участия. Клиент не staff-роль;
Barista/Administrator — обязательные роли employee. Один человек может
использовать оба контекста с тем же телефоном после клиентской регистрации.
[Политики и lifecycle](../30-domain/Identity-and-access.md) определяют подробные
условия; модель товара сохраняет [ADR-008](../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md).

## Контексты и права

| Возможность                                          | Зарегистрированный клиент, customer-контекст | Включённый Barista, staff-контекст | Включённый Administrator, staff-контекст |
| ---------------------------------------------------- | :------------------------------------------: | :--------------------------------: | :--------------------------------------: |
| Публичное меню                                       |                      ✓                       |                 ✓                  |                    ✓                     |
| Создание, просмотр и повтор только своих заказов     |                      ✓                       |                                    |                                          |
| Push о собственном заказе                            |                      ✓                       |                                    |                                          |
| Очередь и этапы приготовления                        |                                              |                 ✓                  |                    ✓                     |
| Push о новом заказе                                  |                                              |                 ✓                  |                                          |
| Управление доступностью                              |                                              |                 ✓                  |                    ✓                     |
| Управление каталогом и ценами                        |                                              |                                    |                    ✓                     |
| Сотрудники: список, создание, роль, рабочий доступ   |                                              |                                    |                    ✓                     |
| Клиенты: отдельный поиск и чтение без staff-действий |                                              |                                    |                    ✓                     |
| Настройки сервиса                                    |                                              |                                    |                    ✓                     |

Global block запрещает оба защищённых контекста. Отключение работы запрещает
только staff-доступ, сохраняя роль, клиента, его сеансы/уведомления и историю.
Для существующих push v2 достаточно аутентифицированного customer-контекста
до регистрации; это не разрешает заказы и не добавляет человека в «Клиенты».
Administrator может получать собственные customer-уведомления через отдельный
customer-контекст, но не staff new-order push.

## Управление доступом

Новый UI в `/users` разделяет «Сотрудники» и «Клиенты». Подробные требования —
[Back-office UI](../50-interfaces/Back-office-UI.md#пользователи-и-настройки).
Глобальная account-блокировка остаётся опубликованной административной
возможностью без нового customer administration UI; рабочая кнопка использует
только employee access. Self-disable/self-global-block/self-demotion и потеря
последнего действующего administrator запрещены сервером.

[HTTP-контракт](../50-interfaces/Authentication-API.md) определяет новые проекции
и сохранённые account-команды; scalar role не авторизует. Bootstrap и прежний
`npm run staff -- upsert` сохраняются с явным
[переводом в участия](../../backend/docs/40-data/PostgreSQL-and-migrations.md#bootstrap-и-существующая-cli).
Имя OTP/CLI/bootstrap-аккаунта может быть null без выдуманного значения.
