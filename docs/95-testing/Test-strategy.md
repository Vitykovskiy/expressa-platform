# Требования к качеству и уровни тестирования

## Безопасность

- HTTPS во всех сетевых средах;
- точный список разрешённых origins;
- Secure, HttpOnly и SameSite для refresh cookie;
- ограничение частоты OTP и чувствительных API;
- хэширование OTP и refresh token;
- ролевые guard-проверки на backend;
- маскирование телефона и токенов в журналах;
- параметризованный доступ к данным через ORM;
- секреты через хранилище CI/CD и переменные окружения;
- журналирование действий сотрудников.

## Производительность

- публичное меню: p95 ответа API до 500 мс при прогретой базе;
- операции заказа: p95 до 700 мс, исключая SMS;
- очередь back-office: первая загрузка до 2 секунд в тестовой сети;
- основной JavaScript front-office после сжатия: целевой бюджет до 300 КБ;

## Доступность интерфейсов

- целевой уровень WCAG 2.1 AA;
- стандартная поддержка клавиатуры для форм и элементов управления; отдельные горячие клавиши не разрабатываются;
- видимый фокус;
- корректные подписи полей;
- контраст основных состояний;
- текстовые обозначения дополняют цветовые статусы;
- интерактивные зоны мобильного интерфейса от 44×44 px.

## Уровни

| Уровень | Backend | Front-office | Back-office |
|---|---|---|---|
| Модульные тесты | доменные правила, сервисы | stores, composables, форматирование | stores, composables, права |
| Интеграционные тесты | PostgreSQL, транзакции, адаптеры | API-клиент с mock server | API-клиент с mock server |
| Компонентные тесты | — | Storybook interactions | Storybook interactions |
| Контрактные тесты | OpenAPI и схемы | снимок OpenAPI | снимок OpenAPI |
| E2E | API-сценарии | пользовательский браузерный путь | рабочий браузерный путь |
| Smoke | полный API-маршрут | меню → заказ → история | очередь → выдача |
