# API меню

Публичное меню нужно front-office для просмотра и локальной сборки конфигурации товара. Подробные поля и типы — [OpenAPI](../../backend/openapi/openapi.json); здесь закреплена граница реализованного контракта.

| Метод и путь | Успех | Назначение |
|---|---:|---|
| `GET /api/v1/public/menu` | `200` | Публичное меню и состояние приёма новых заказов |

Ответ — `PublicMenuDto`: `acceptsNewOrders` и упорядоченные `categories`. Категория содержит `products`; товар содержит тип `DRINK` или `OTHER`, цену либо варианты напитка и `modifierGroups`; группа содержит правила выбора и `options`. У `DRINK` цена товара равна `null`, варианты имеют размеры `S`/`M`/`L`; у `OTHER` список вариантов пуст. Денежные поля передаются целыми копейками.

Endpoint публичный и только читает каталог. Сейчас `acceptsNewOrders` возвращается как `true`; клиент использует поле для отображения состояния, а не как разрешение на создание заказа.
