# Содержательные комментарии

Применяется к новому и изменяемому авторскому коду по [общему стандарту](Clean-code.md). Приёмка — [общий DoD](Definition-of-Done.md).

Сначала проясняются имя и структура. Комментарий добавляет неочевидную причину,
инвариант, контракт, математическое основание или подтверждённое ограничение.
Он точен, самодостаточен рядом со своим условием и меняется вместе с кодом.
Неочевидные ошибки, эффекты и порядок публичной операции поясняются;
JSDoc для каждой внутренней функции не требуется.

Новые и изменяемые авторские комментарии пишутся по-русски; идентификаторы,
API, команды и дословные цитаты сохраняют написание. Обязательные лицензионные
и авторские уведомления сохраняются. Подробное внешнее описание заменяется
ссылкой с местным смыслом, чужие настройки и defaults не копируются.

В области изменения нет мёртвого кода, отладки, закомментированного
production-кода, устаревших пояснений и отключённых проверок. Декоративные
разделители не заменяют структуру; журнал правок остаётся в Git. TODO
не заменяет требуемую реализацию. Несвязанный рефакторинг не добавляется.
Порядок объявлений поддерживает чтение сценария, сохраняя инициализацию
и framework-контракты; логические блоки разделяются по
[правилам читаемости](../40-quality/Vue-code-style.md#форматтер-линтер-и-пустые-строки).

## Наблюдение при приёмке

Сопоставьте каждое изменённое пояснение с кодом и контрактом рядом. Ложный default, устаревший эффект или TODO вместо результата блокируют приёмку.

**Учебная иллюстрация, не API Expressa.** Контракт `loadOptions()` возвращает проверенные настройки либо ошибку; default не предусмотрен. Пустой `catch` с комментарием «Используем настройки по умолчанию» лжёт. Для этого синхронного контракта оставьте `options = loadOptions();` и передайте ошибку существующему владельцу обработки. Это не предписание удалять обработку ожидаемых отказов.

При переводе исключающей верхней границы в включённый индекс комментарий «Внешний контракт задаёт исключающую границу» объясняет `endExclusive - 1`. «Вычитаем один» пересказывает код. Непустота диапазона подтверждается контрактом, не комментарием.
