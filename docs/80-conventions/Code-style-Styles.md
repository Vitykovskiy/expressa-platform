# Стили и общие параметры UI

Применяется к изменённым стилям обоих клиентов. Подробный владелец размещения стилей, tokens, `:deep()`, `!important` и raw values — [Vue style](../40-quality/Vue-code-style.md#стили-и-доказательства). Семантика представления и общая ответственность берутся из UI-контракта конкретного клиента.

## Общий владелец и граница продукта

Для front-office читайте [UI-контракты](../../front-office/docs/30-conventions/UI-contracts.md). Для новой версии back-office действуют [ADR-011](../20-architecture/ADR/ADR-011-back-office-clean-slate.md), [технический DoD](Code-Definition-of-Done-back-office.md) и [продуктовый контракт](../50-interfaces/Back-office-UI.md). Удалённая палитра, старые имена компонентов и tokens не восстанавливаются по source-проекту или прежнему UI. В текущем checkout локальный `back-office/docs` не содержит опубликованного контракта темы; отсутствие не разрешает выдумать его значения.

## Пример семантического параметра

**Учебная иллюстрация, не имена tokens Expressa.** Условная тема уже определяет `--surface-card` и `--text-primary` для двух тем. Локальная панель с фиксированными `background: #fff` и `color: #111` копирует значения светлой темы, хотя ей нужны роли карточки и основного текста.

Исправление применяет `background: var(--surface-card)` и `color: var(--text-primary)`. Семантика светлой темы сохраняется, сменой темы управляет один владелец. Реальная реализация использует только существующие product tokens; пример не поручает добавить эти имена. Совпадение текущего цвета разных семантических ролей не требует объединить их.

## Наблюдение при приёмке

Reviewer читает SFC и реальные определения tokens, проверяет обоснование исключений рядом с CSS и отсутствие проникновения во внутренний DOM библиотеки. Неподтверждённый token или отдельная копия общей палитры блокируют приёмку. Последний визуальный результат принимается по [UI DoD](../40-quality/Definition-of-done.md), независимо от успешной сборки. PrimeNG, Tailwind и `--app-*` из Barsim не становятся стеком или темой Expressa.
