# Владение состоянием

Применяется к новому и изменяемому авторскому коду по [общему стандарту](Clean-code.md). Приёмка — [общий DoD](Definition-of-Done.md).

## Владелец и контекст

У состояния определены владелец, срок жизни и правила смены контекста.
Локальное UI-состояние остаётся локальным; предметное публикуется через
контракт владельца без обхода его инвариантов изменяемой ссылкой.
Чистое производное вычисляется, а не копируется в отдельный источник.
Черновик сохраняет предусмотренные правила пользовательского редактирования
и сброса; смена контекста не оставляет активными чужие данные и ошибки.
Смена сессии учитывает зависимое состояние по контракту сценария.

В Vue применяются `computed`, типизированные входы/события, composables и Pinia
по [Vue style](../40-quality/Vue-code-style.md) и контурному DoD. Эффекты
не поддерживают лишнюю копию производного и не перезаписывают черновик из-за
несвязанного изменения. Шаблон остаётся декларативным; список сохраняет
предметную идентичность элементов. Формат SFC, props/emits/slots, attrs,
тема, tokens и исключения CSS принадлежат Vue style, без копирования
Angular, PrimeNG или Tailwind-рецептов исходника.

## Наблюдение при приёмке

Для открытия, смены контекста, его недопустимости и завершения владельца установите судьбу прежних данных, ошибок и активной работы. Недопустимый новый контекст отзывает прежний; отсутствие новой загрузки не оставляет чужую карточку активной. Механизм определяется существующим lifecycle, без обязательного нового экземпляра store. Актуальность завершений — [асинхронные сценарии](Code-style-Async.md).

## Пример производного и черновика

**Учебная иллюстрация, не модель Expressa.** В локальном Vue-состоянии список выбранных имён — единственный источник, количество всегда равно длине. Антипример хранит независимо список и `count`, затем копирует длину через `watch`: появляется вторая изменяемая величина, которая может отстать. Исправление — чистый `computed` от списка. Изменение списка выполняет команда владельца; readonly-обещание потребителю не должно оставлять обход инварианта вложенной изменяемой ссылкой.

Редактируемое название отличается: пользователь вправе менять черновик независимо от исходной записи. Автоматическая повторная инициализация при каждом изменении несвязанного состояния уничтожает ввод. Владелец задаёт, какой переход действительно сбрасывает черновик, а какой сохраняет его. Выбор `computed` вместо черновика здесь не исправление: он меняет контракт редактирования. Механика `watch` и cleanup принадлежит [Vue style](../40-quality/Vue-code-style.md#реактивность-и-границы-компонентов).
