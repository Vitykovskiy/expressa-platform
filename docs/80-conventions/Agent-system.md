# Агентная система Expressa

Skills устанавливаются глобально; профили ролей и их регистрация находятся в
`.codex/agents` и `.codex/config.toml`. После обновления skills или профилей
запустите новую сессию: текущая сессия могла загрузить прежнюю конфигурацию.

## Оркестрация

Оркестрацию включает глобальный skill `codex-orchestration-pact`. Root
работает только диспетчером: создаёт задачу, хранит цель и состояние, запускает
роль из `next_transition`, проверяет envelope и существование артефакта,
атомарно обновляет `state.yaml`, передаёт дословный вопрос роли и создаёт или
возобновляет handoff. Если пользователь выбирает модель и глубину рассуждения
при запуске, root-оркестратор использует `gpt-5.6-luna` с `low`.

`state.yaml` — единственное оперативное состояние. Полные отчёты, доказательства
и handoff хранятся в `.codex/tmp/tasks/<task-id>/`; resume читает корневой
`AGENTS.md`, глобальный pact оркестрации, handoff, `state.yaml` и следующий или
незавершённый envelope.

Решение пользователя требуется, когда его нельзя вывести из требований и
принятых charter/preferences: при изменении смысла или процесса, удалении
функции, публичном API, риске потери данных или безопасности, необратимом выборе
либо равноценных вариантах без принятого предпочтения.

`quality_owner` ведёт открытую кампанию качества: выбирает минимально достаточный
способ наблюдения, поддерживает charter/preferences, приоритизирует проблемы и
формирует следующую небольшую партию. Developer собирает доказательства,
`reviewer` принимает одно назначение, `integration_reviewer` проверяет кампанию;
root маршрутизирует только статусы и ссылки.

## Первая кампания качества

Запусти кампанию улучшения Expressa по глобальному skill `expressa-quality-pact`. Root работает только как диспетчер. Создай задачу `expressa-quality-baseline`. Первым запусти `quality_owner`: он должен исследовать текущее приложение, существующие средства наблюдения и выбрать первую небольшую партию. Production-код до принятой декомпозиции не изменять.
