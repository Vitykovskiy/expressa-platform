# Владельцы инженерных соглашений

[INDEX](INDEX.md) выбирает контур и вид изменения, [карта стиля](Code-style.md) — область кода. Эта карта объясняет роль источников, не повторяя их требования.

| Источник                                                                                                         | Что подтверждает и где заканчивается                                                                    |
| ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [AGENTS](../../AGENTS.md)                                                                                        | Полномочия, абсолютные ограничения и маршрут обязательных skills. Не принимает runtime.                 |
| [Clean-code](Clean-code.md), [тематическая семья](Code-style.md)                                                 | Требуемые принципы, условия и исключения. Документ не доказывает соответствие существующего кода.       |
| [Общий DoD](Definition-of-Done.md), три контурных DoD в [INDEX](INDEX.md)                                        | Наблюдения и доказательства приёмки. Независимое review не заменяет пользовательскую приёмку.           |
| [Архитектура](../20-architecture/INDEX.md), [ADR](../20-architecture/ADR/INDEX.md)                               | Границы приложений и действующие решения; статус решения не доказывает миграцию.                        |
| [Vue style](../40-quality/Vue-code-style.md), [UI DoD](../40-quality/Definition-of-done.md)                      | Канонические frontend/UI-условия. Тематические Vue/styles-ноты только маршрутизируют и иллюстрируют их. |
| [ESLint/Prettier](ESLint-config.md), manifest и конфигурация                                                     | Фактически настроенные механические проверки и их охват; semantic review остаётся отдельным.            |
| [Документационные нормы](../00-meta/INDEX.md), [протокол обновления](../00-meta/Update-protocol.md)              | Актуальность текста, тип источника, ссылки и связанная трасса.                                          |
| [Git](Git-workflow.md), [полномочия](Allowed-without-confirmation.md), [подтверждение](Requires-confirmation.md) | Маршрут работы и доставки со ссылкой на AGENTS; не новое разрешение выполнить операцию.                 |
| [Agent-system](Agent-system.md), task state/reports                                                              | Организация и доказательства процесса; отчёт не изменяет нормативный контракт.                          |

История, снимок ТЗ, план, implementation и accepted ADR различаются по [приоритету источников](../00-meta/Source-precedence.md). Противоречие с действующей нормой нельзя узаконить ссылкой на текущий код. Для отсутствующего back-office workspace сохраняются корневой технический DoD и ADR-011, а локальный контракт остаётся недоступным, пока не появится реальный источник.
