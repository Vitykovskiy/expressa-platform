# Компоненты и шаблоны Vue

Для нового и изменяемого Vue-кода обоих клиентов действует [общий стандарт](Clean-code.md). Подробный владелец SFC, props/emits/slots/attrs, реактивности и Vuetify — [Vue style](../40-quality/Vue-code-style.md); эта нота связывает его с общей семьёй и объясняет приёмку.

## Маршрут по области

| Область         | Канонический раздел                                                                            | Что наблюдать                                                                  |
| --------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| SFC и шаблон    | [Компонент и шаблон](../40-quality/Vue-code-style.md#компонент-и-шаблон)                       | Порядок блоков, декларативное представление, вычисления и стабильный key.      |
| Ответственность | [Реактивность и границы](../40-quality/Vue-code-style.md#реактивность-и-границы-компонентов)   | Источник состояния, чистый computed, эффект и cleanup.                         |
| Публичный API   | [Контракты и атрибуты](../40-quality/Vue-code-style.md#контракты-и-атрибуты)                   | Явные входы/события, модель только при двустороннем контракте, передача attrs. |
| Общий UI        | [Vuetify и переиспользуемый UI](../40-quality/Vue-code-style.md#vuetify-и-переиспользуемый-ui) | Повторная продуктовая ответственность, граница wrapper, тема и семантика.      |

Компонент-контейнер координирует сценарий в пределах своего контурного DoD; отображающий компонент получает подготовленные данные и сообщает события. Область состояния — [отдельный владелец](Code-style-State.md), транспорт — [API-граница](Code-style-Data.md). Angular `OnPush`, standalone, signal inputs, `inject()` и provider-механика сюда не переносятся.

## Пример идентичности списка

**Учебная иллюстрация, не экран Expressa.** Уже проверенные строки имеют уникальный стабильный ID; список может переставляться, выбор сообщает ID без загрузки. Антипример связывает `:key` с индексом. После перестановки DOM и локальное состояние строки следуют позиции, а не предметной записи.

Исправление использует `:key="row.id"`; название и событие выбора ID сохраняются, порядок соответствует входу. Количество строк при необходимости выводится чистым `computed`, без копии счётчика. Для неизменяемого списка без локального состояния элементов действует исключение Vue style; универсальный запрет индекса не вводится.

## Наблюдение при приёмке

Сопоставьте template, script и потребителя публичного API по указанным разделам. Транспорт в отображающем компоненте, скрытая мутация props либо потеря предметной идентичности блокируют приёмку. Исходник подтверждает структуру; изменённый видимый UI дополнительно проходит [UI DoD](../40-quality/Definition-of-done.md) и [процесс визуальной работы](../40-quality/Validation-strategy.md#процесс-визуальной-работы). Документационный пример не доказывает runtime.
