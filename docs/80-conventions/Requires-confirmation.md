# Границы подтверждения

## Основной источник

Точный перечень действий с отдельным явным подтверждением задан в [AGENTS, Границы автономности](../../AGENTS.md#границы-автономности): force-push, tag, PR, major-upgrade, неподдерживаемая среда, крупное архитектурное изменение и указанное там удаление публичного API, используемой feature, core-сервиса или endpoint. Перечень не заменяется аналогичными правилами Barsim.

## Порядок действия

Исполнитель сначала сопоставляет операцию с исходным и последующими поручениями. Уже разрешённое действие в согласованных пределах не требует повторного подтверждения. Если нужного разрешения нет, останавливается только зависимая операция; вопрос содержит конкретное подготовленное действие, причину и применимый источник ограничения. Ответ пользователя не выводится из молчания или успешной проверки.

Независимая разрешённая работа продолжается. До подтверждения не выполняются необратимое расширение или публикация. Работа с тестами отдельно подчиняется [абсолютному правилу](../../AGENTS.md#абсолютное-правило-до-приёмки); разрешение на deploy его не отменяет. [Маршрут обычных действий](Allowed-without-confirmation.md) не является новым разрешением.
