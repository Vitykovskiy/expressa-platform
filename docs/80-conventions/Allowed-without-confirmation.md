# Действия в пределах поручения

## Основной источник

Полномочия и абсолютные ограничения принадлежат [AGENTS](../../AGENTS.md), эта нота помогает выбрать применимый раздел. Порученное обратимое действие выполняется в пределах задачи; новая инструкция или полезность инструмента не расширяет разрешённый scope.

| Ситуация                               | Канонический источник и действие                                                                                                                                                                                    |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Правка кода или текста уже поручена    | Прочитать применимые правила через [INDEX](INDEX.md), сохранить посторонние изменения, выполнить согласованную область и разрешённые проверки.                                                                      |
| Возникла идея нового средства проверки | Поручение результата не разрешает новый тест, validator, script или процессную автоматизацию. Сохраняется отдельный прямой запрос на средство.                                                                      |
| Нужны существующие проверки            | Выбрать их фактический охват по [конфигурации](ESLint-config.md), без тестов и расширения diff.                                                                                                                     |
| Пользователь поручил deploy            | Применить разрешение и условия [границ автономности](../../AGENTS.md#границы-автономности); отдельные действия, для которых там нужно явное подтверждение, сохраняют своё условие.                                  |
| Нужны тесты                            | Применить [абсолютное правило](../../AGENTS.md#абсолютное-правило-до-приёмки): независимый review и статические проверки не являются пользовательской приёмкой; приёмка документации не запускает тесты приложения. |

## Наблюдаемое завершение

Результат указывает сделанное, реальное доказательство и оставшиеся ограничения. Выполнение разрешённой правки не означает разрешение публикации. Неразрешённое зависимое действие остаётся остановленным, независимая разрешённая работа продолжается по [границам подтверждения](Requires-confirmation.md).
