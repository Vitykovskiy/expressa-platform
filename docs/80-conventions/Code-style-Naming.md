# Предметные имена

Применяется к новому и изменяемому авторскому коду по [общему стандарту](Clean-code.md). Приёмка — [общий DoD](Definition-of-Done.md).

Имя раскрывает предмет, роль, действие и единицу на уровне своего контракта.
Команда называет действие, предикат — условие. Общие `data`, `info`, `manager`
и `process` не скрывают назначение. Один смысл использует один термин;
одинаковое слово не маскирует разные операции. Значимый дополнительный эффект
отражён в имени.

Имена различимы и удобны для поиска в своей области: предметные
`sourceItems`/`destinationItems` предпочтительнее `items1`/`items2`.
Общепринятые API, DTO, URL и короткий индекс локального цикла допустимы;
самодельные сокращения, шутки и кодирование типа/видимости в имени — нет.
Контекст добавляется при неоднозначности, без повторения всей цепочки каталогов.
Framework lifecycle, внешний API и действующие публичные контракты сохраняются.
Форматы имён Vue принадлежат [Vue style](../40-quality/Vue-code-style.md#имена-комментарии-и-проверка).

## Наблюдение при приёмке

Reviewer читает объявление и затронутые вызовы. Имя, скрывающее направление, единицу или эффект, отклоняется с указанием конкретной неоднозначности.

**Учебная иллюстрация, не API Expressa.** `copy(a1, a2)` не раскрывает направление. Для заданной мутации второго списка точнее `copyTitles(sourceTitles, destinationTitles)`. Если результат новый и вход неизменен, контракт точнее выражает `normalizeTitles(sourceTitles)`. Переименование не разрешает добавить скрытую мутацию.
