# Charter качества продукта

Цель Expressa — понятный, целостный и предсказуемый продукт. Приоритеты: корректность, понятность, согласованность, доступность, визуальная точность.

Качество оценивается по работающему приложению, а не только по коду или прохождению тестов. Каждый экран имеет ясное основное действие; одинаковые задачи решаются одинаковыми интерфейсными паттернами. Состояния `loading`, `empty`, `error`, `success` и `disabled` — часть продукта. Адаптивность проверяется на фактических границах приложения.

Найденный дефект фиксируется с экраном, состоянием, viewport и доказательством. Независимый reviewer выполняет итоговую приёмку реализации. `quality_owner` владеет приоритетом и следующей партией; root не оценивает интерфейс.
