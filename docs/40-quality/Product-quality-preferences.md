# Предпочтения качества продукта

- Один результат не имеет дублирующих действий в одном контексте.
- Для одной неуспешной операции показано одно понятное действие восстановления.
- Технические коды, включая `INTERNAL_SERVER_ERROR`, не являются основным пользовательским сообщением.
- Подпись и положение кнопки соответствуют фактически выполняемому действию.
- Плавающий элемент используется только при доказанной необходимости и не дублирует постоянную настольную навигацию.
- Интерфейс избегает визуальной перегрузки.
- Отступы, размеры и иерархия выглядят системно, а не как набор локальных исключений.
- Актуальность макета проверяется, а не предполагается.
- Сырое замечание пользователя сначала становится проверяемой гипотезой; `quality_owner` ищет тот же класс проблемы в остальных экранах.
- Новое правило закрепляется после подтверждения фактами либо явного решения пользователя.
