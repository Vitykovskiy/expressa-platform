# Жизненный цикл заказа

- **BR-005.** Клиент оплачивает заказ на кассе при получении.
- **BR-006.** После получения оплаты сотрудник переводит заказ из стадии `Готов` в стадию `Выдан`.
- **BR-007.** Выдача доступна для заказа на стадии `Готов`.
- **BR-011.** Порядок стадий направлен вперёд: `Оформлен` → `Принят` → `Готовится` → `Готов` → `Выдан`.

### 8.4. Заказы

- **FR-ORD-001.** Авторизованный customer создаёт заказ из подтверждённой корзины.
- **FR-ORD-002.** Запрос создания содержит ключ идемпотентности.
- **FR-ORD-003.** Повтор запроса с тем же ключом возвращает ранее созданный заказ.
- **FR-ORD-004.** Заказ получает человекочитаемый номер формата `YYYYMMDD-NNN`.
- **FR-ORD-005.** Начальная стадия заказа — `Оформлен`.
- **FR-ORD-007.** Заказ содержит снимки товара, добавок, количества, цен и размера напитка при его наличии.
- **FR-ORD-008.** Заказ содержит итоговую сумму в копейках.
- **FR-ORD-009.** Back-office показывает очередь с фильтрами по стадии и поиском по номеру.
- **FR-ORD-010.** Карточка заказа показывает состав, сумму, время, клиента и историю изменения стадий.
- **FR-ORD-011.** Barista и administrator переводят заказ по разрешённым переходам.
- **FR-ORD-012.** Каждый переход содержит автора, время, предыдущую и новую стадию.
- **FR-ORD-014.** Back-office обновляет очередь опросом API с интервалом до 5 секунд.
- **FR-ORD-015.** Front-office обновляет текущий заказ опросом API с интервалом до 10 секунд, пока открыта страница заказа и заказ не выдан. При сворачивании приложения или уходе со страницы опрос прекращается, при возвращении — возобновляется.
- **FR-ORD-016.** Страница заказа показывает текущую стадию, состав и сумму.

### 8.5. Оплата при получении

- **FR-PAY-001.** Клиент оплачивает заказ на кассе после перехода заказа в стадию `Готов`.
- **FR-PAY-002.** После получения оплаты сотрудник нажимает `Выдать` и переводит заказ из стадии `Готов` в стадию `Выдан`.
- **FR-PAY-003.** В корзине и карточке заказа front-office показывает текст `Оплата на кассе при получении`.

## 9. Модель состояний заказа

### 9.1. Стадия исполнения

| Код | Отображение | Следующая стадия | Исполнитель |
|---|---|---|---|
| `CREATED` | Оформлен | `ACCEPTED` | Barista, Administrator |
| `ACCEPTED` | Принят | `PREPARING` | Barista, Administrator |
| `PREPARING` | Готовится | `READY` | Barista, Administrator |
| `READY` | Готов | `ISSUED` | Barista, Administrator |
| `ISSUED` | Выдан | терминальная стадия | — |

### 9.2. Полный рабочий маршрут

`CREATED` → `ACCEPTED` → `PREPARING` → `READY` → `ISSUED`.
