# Каталог и меню

Публичное меню, чтение административного каталога и команды товаров работают только через v3 API. Категории и группы модификаторов используют текущие v2 операции. Методы и схемы — [OpenAPI](../../backend/openapi/openapi.json).

Товар имеет одну цену с необязательной подписью порции либо упорядоченные `priceChoices`. Модель вариантов S/M/L удалена. Полная граница замены — [ADR-008](../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md); конфигурация позиции — [отдельный контракт](Product-configuration.md).

## Команды диалогов back-office

Целевой контракт [ADR-012](../20-architecture/ADR/ADR-012-back-office-source-contract.md)
добавляет `/api/v3/backoffice/menu/*` поверх того же каталога. Он меняет прежнее
ограничение композиции формы, сохраняя действующие v2/v3 операции и предметные
инварианты. Это отдельные атомарные команды сохранения, а не новая модель меню.

Создание категории получает серверные `description=''`, следующий порядок и
`isActive=true`; сохранение имени и выбранной группы выполняется в одной
транзакции с аудитом. При редактировании отсутствующий `optionGroupId` сохраняет
все текущие связи; явно переданные UUID или `null` заменяют их одной группой или
пустым набором. Скрытые поля категории сохраняются.

Новая группа — активная, необязательная, `single`, `minSelect=0`, `maxSelect=1`,
без опций. Переименование сохраняет ограничения и опции. Добавление опции
использует явно переданную целую цену, следующий порядок,
`isDefault=false`, `isAvailable=true`; редактирование сохраняет остальные поля.
Обе команды проверяют допустимость всей действующей группы.

Новый товар получает `description=''`, следующий порядок категории и
`isActive/isAvailable=true`. Клиент передаёт всю выбранную ценовую ветвь: одну
цену и пустые `priceChoices` либо `price=null` и минимум две ценовые опции по
сохраняемому v3-инварианту. S/M/L — только начальные подписи новых опций.
Редактирование сохраняет скрытые поля, существующие ID и доступность ценовых
опций; чужие, повторные или архивные ID отклоняются. Удаление опций и смена
ценовой ветви являются явной полной заменой с подтверждением на клиенте.
Название категории, товара и группы не определяет их идентичность.
