# Конфигурация товара

- **BR-020.** Уникальная конфигурация позиции определяется товаром, размером для напитка и набором добавок.
- **BR-021.** Каждая обязательная группа добавок содержит бесплатный набор вариантов по умолчанию, который соответствует допустимому количеству выбранных вариантов.

Клиентская конфигурация создаётся по публичному меню: для `DRINK` выбирается доступный `M`, иначе первый доступный вариант; для обязательных групп — доступные бесплатные варианты по умолчанию. Добавление в корзину допустимо только при выбранном доступном варианте напитка и соблюдении `min_select`/`max_select` каждой группы. Идентичность позиции корзины — товар, вариант напитка при наличии и отсортированный набор вариантов добавок.
