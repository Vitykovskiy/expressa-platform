# Конфигурация товара

В текущей реализации конфигурация заказа содержит товар, вариант `S/M/L` для
`DRINK` и выбранные варианты модификаторов. Backend при создании заказа сверяет
их с актуальным меню, допустимым количеством выбора и пересчитывает сумму;
клиентский итог не является источником цены. [Revalidation](../../backend/src/orders/domain/order-revalidation.ts),
[order API](../../backend/openapi/openapi.json).

Группы модификаторов товара дополняют, но не заменяют назначения категории;
повторная группа устраняется при построении публичной и order-проекций.

Front-office сейчас строит начальное состояние из публичного меню: доступный
`M`, иначе первый доступный размер; обязательные бесплатные
default-модификаторы. Изменение пользователя ограничено правилами группы до
отправки, но backend остаётся окончательной проверкой. [Клиентский сценарий](../../front-office/docs/30-features/Menu-and-configuration.md),
[frontend tests](../../front-office/src/features/menu/product-configuration.spec.ts).

## Принятое целевое состояние

У товара с одной ценой конфигурация не содержит выбора цены. Необязательная
`portionLabel` показывается рядом с ценой как статический текст. У товара с
двумя и более ценами конфигурация содержит обязательный `priceChoiceId`, а
покупатель видит обычную группу `Порция` с точными подписями и ценами.

Начально выбирается первый доступный вариант в административном порядке;
отдельного default нет. Недоступные варианты видимы, заблокированы и отмечены
`Нет в наличии`. Если доступных вариантов нет, товар нельзя добавить в
корзину. Backend перед созданием заказа по-прежнему проверяет текущую цену,
доступность и модификаторы и пересчитывает итог.

Корзина, checkout и новый заказ несут стабильный id выбранной цены, а история
показывает снимок подписи и цены. Повтор не подбирает замену по тексту;
архивный, отсутствующий или недоступный id требует нового выбора. Модификаторы
не становятся вариантами цены. Нормативные инварианты принадлежат
[ADR-006](../20-architecture/ADR/ADR-006-product-variant-portions.md); они ещё не
реализованы полностью.
