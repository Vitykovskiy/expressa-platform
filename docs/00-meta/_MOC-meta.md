# Обновление знания после изменения

Локальная карта правил — [INDEX.md](INDEX.md). Для изменения документа соедините источники:

1. [Правила чтения](How-to-use-this-vault.md) выбирают область и роль документа.
2. [Приоритет источников](Source-precedence.md) отделяет ожидаемое от фактического и исторического.
3. [Формат](Naming-conventions.md) определяет имя, метаданные и ссылки.
4. [Протокол обновления](Update-protocol.md) связывает текст с затронутым кодом / контрактом.
5. [Модель покрытия](Coverage-model.md) связывает исходные требования с предметными нотами; [словарь](Glossary.md) задаёт общий язык.

Для вопроса о происхождении читайте [источники](../_sources/README.md) и [журнал](../_journal/README.md), не выдавая их за текущий runtime.
