# Словарь терминов

Термины согласованы с [обзором продукта](../10-overview/Project-overview.md), [доменной моделью](../30-domain/Domain-model.md) и [ADR-008](../20-architecture/ADR/ADR-008-v3-catalog-orders-cutover.md).

| Термин               | Значение и владелец                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| Expressa / Экспресса | Внутреннее имя системы / название customer-интерфейса.                                         |
| Контур               | Автономно собираемое приложение: backend, front-office или back-office.                        |
| Customer             | Покупатель; читает меню и работает со своими заказами.                                         |
| Barista              | Сотрудник; ведёт очередь, стадии и оперативную доступность.                                    |
| Administrator        | Сотрудник с правами barista и управлением каталогом.                                           |
| Каталог              | Административная модель категорий, товаров, цен и модификаторов.                               |
| Публичное меню       | Серверная проекция каталога для покупателя.                                                    |
| `priceChoices`       | Упорядоченные ценовые опции товара со стабильными id; замена удалённой модели вариантов S/M/L. |
| `portionLabel`       | Текстовая подпись порции или цены; не величина для автоматического пересчёта.                  |
| Модификатор          | Добавка или настройка товара из группы опций.                                                  |
| Снимок заказа        | Сохранённые на момент заказа наименования, цены, подписи и состав; не текущий каталог.         |
| Идемпотентность      | Повтор создания с тем же customer, ключом и телом возвращает сохранённый заказ.                |
| Push association     | Серверная связь подписки с аккаунтом; не browser permission.                                   |
| Одноразовая база     | База local/test/development, пересоздаваемая из текущих схемы и seed.                          |
| Контракт             | Норма ожидаемого поведения в указанной области.                                                |
| Runtime              | Работающее приложение; чтение исходников не является его наблюдением.                          |
| Приёмка              | Явный результат проверки или решение пользователя; не наличие документа либо тестового файла.  |
