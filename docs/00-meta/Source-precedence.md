# Приоритет источников

Источники различаются по назначению. Они не образуют безусловный список, где
реализация отменяет требование.

- **Нормативные** источники задают требуемое состояние в своей области:
  действующие инструкции пользователя и `AGENTS.md`, ТЗ для продуктовых
  требований, принятый ADR для архитектурного решения, применимый DoD,
  UI-контракт, стиль и принятые product preferences. Норма безопасности или
  DoD не отменяется preference. Явное актуальное уточнение пользователя об UX
  применяется к ещё не реализованному ожидаемому поведению.
- **Описательные** источники показывают фактическое состояние: код, OpenAPI,
  конфигурация и runtime; тест — только выполненное утверждение в условиях
  прогона. Они исправляют неточное описание реализации, но не делают
  нормативным нарушение требования. Наблюдаемая ошибка становится finding, а
  не образцом desired UX.
- **Оперативные** источники задают движение работы: `state.yaml` определяет
  разрешённый переход, inventory и findings хранят покрытие и приёмку,
  handoff кратко указывает продолжение, архив сохраняет историю. Ни старое
  назначение, ни handoff не меняют продуктовую норму; при расхождении с ними
  сверяйте `state.yaml` и применяйте восстановление кампании.

Для требований Expressa нормативен `Expressa_MVP_Техническое_задание.md`. [Бэклог](../10-overview/Backlog.md) — текущий источник планирования, [покрытие бэклога](../10-overview/Backlog-coverage.md) — источник трассируемости; они не изменяют требования ТЗ.

Принятый ADR имеет приоритет над соответствующим архитектурным положением ТЗ. [ADR-001](../20-architecture/ADR/ADR-001-Root-repository-structure.md) заменяет требование отдельных Git-репозиториев правилом единого корневого репозитория с тремя автономно собираемыми приложениями.

При конфликте действующих норм зависимое назначение не готово: владелец
решения разрешает его по применимым источникам, а architect нужен для реального
технического выбора. До этого допустимо независимое исследование, но нельзя
закреплять спорное поведение кодом или тестом.
