# Документация backend Expressa

Backend запускает NestJS-приложение и является местом для серверных модулей
Expressa. Предметные модули, HTTP-контракты и подключение PostgreSQL будут
описываться рядом с их реализацией.

Точка входа: [`../src/main.ts`](../src/main.ts). Корневой NestJS-модуль:
[`../src/app.module.ts`](../src/app.module.ts).
