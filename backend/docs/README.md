# Документация backend

Здесь собраны правила и проверяемые сведения о сервере Expressa. Карта ведёт к
действующим контрактам; код, миграции, тесты и OpenAPI остаются источниками
истины.

## Структура каталога

```text
backend/docs/
├── 00-meta/            # правила ведения и проверки документации
├── 10-architecture/    # границы слоёв, модулей и архитектурные решения
├── 30-domains/         # авторизация, каталог и заказы
├── 40-data/            # PostgreSQL, миграции и транзакции
├── 50-api/             # HTTP-маршруты и API-контракты
├── 60-operations/      # запуск, окружение и наблюдаемость
├── 80-conventions/     # соглашения и критерии готовности
├── 95-testing/         # стратегии и сценарии проверок
├── _journal/           # исторические записи, не описание runtime
├── _sources/           # сохранённые внешние материалы и их статус
├── COVERAGE.md         # связь runtime-объектов с документацией и проверками
└── INDEX.md             # локальная карта документации
```

Начните с [INDEX.md](INDEX.md). Правила изменений backend — в
[../AGENTS.md](../AGENTS.md).
