# Сохранённые источники backend

Каталог предназначен для внешних материалов, которые нужно сохранить рядом с
документацией backend. Сейчас таких материалов здесь нет: единственный файл —
этот статус.

## Структура каталога

```text
backend/docs/_sources/
└── README.md            # назначение каталога и статус сохранённых материалов
```

Текущее поведение сервера проверяется по коду, миграциям, тестам и
[OpenAPI](../../openapi/openapi.json); маршрут к ним даёт
[карта документации](../INDEX.md). Секреты в этот каталог не добавляются.
